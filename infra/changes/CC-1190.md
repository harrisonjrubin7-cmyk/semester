# CC-1190 · Pass the offline task engine's module flag into the Pages build

## Summary

Adds `VITE_OFFLINE_ENGINE_TASKS` to the two lists in `pages.yml` that carry a
module flag into the production build: the build step's `env:` and the list of
flag names the workflow checks. Nothing else in the workflow changes. The flag
is unset everywhere, so production behaves exactly as before; setting it
later is what turns the engine on, and a device must also opt in.

## Environments and tenants affected

None. No tenant, deploy, permission or setting changes when this merges.
With the variable unset the build is byte-for-byte the same flag state as today.

## Risk

A typo in the new line could fail the Pages build; the same build ran green
in this pull request's own CI. Unset-by-default means a bad value cannot
reach a tenant. Any problem shows in the first Pages run after merge.

## Rollback

Revert this pull request (one commit, minutes). Because the flag is unset,
reverting changes no behaviour.

Pull request CI on #1190: the infrastructure checks and the full suite.
