# CC-1752 · Define the repository security-finding lifecycle

## Summary

Add a pure, test-held lifecycle for security findings. Records carry the exact
scan run, artifact digest and commit; deadlines come from the accepted patch
policy; closure requires an independent passing re-test of the exact fixed
commit. This advances SUP-036 to `building`, not operated or verified.

## Environments and tenants affected

None. The lifecycle has no database, provider, scanner, queue, notification or
runtime adapter. No finding, tenant, environment, credential or deployment is
created or changed by this increment.

## Risk

Repository code could be mistaken for operated remediation evidence, or an
invalid transition could close a finding without proof. Negative tests reject
stale revisions, non-exact commits and digests, missing remediation evidence,
same-run re-tests, mismatched fixed commits and expired risk acceptance. The
register states that no durable store or operated scan history exists.

## Rollback

Revert PR #1752. This removes the pure lifecycle and tests and returns SUP-036
to `not-started`; no environment or tenant rollback is required.
