# CC-1744 · Measure the shared accessibility-tools dialog

## Summary

The real-browser accessibility smoke now opens the shared non-modal
Accessibility tools dialog on each of the seven critical journeys at 375 and
1024 pixels. It verifies the trigger-to-dialog ARIA relationship, expanded
state, focus entry, serious and critical axe results, Escape close and focus
return. The instrument fails closed when any journey-width combination is
missing.

This is one shared non-modal dialog state. Signed-in, error, true-modal, other
interactive, real-device and manual assistive-technology coverage remains
open, and the evidence records preserve those boundaries.

## Environments and tenants affected

None. The change affects automated browser checks and evidence records. It
does not deploy code, publish an artifact, activate a tenant, use institutional
data, change credentials or modify persistent data.

## Risk

The added dialog states increase accessibility-sweep time and can reveal a
journey- or viewport-specific focus, ARIA or axe regression. An unreachable
control, page error, broken dialog relationship, focus failure, missing state
or serious/critical axe finding fails the run rather than silently reducing
coverage.

## Rollback

Revert PR #1744 to restore the destination-only axe sweep. No running
environment needs restoration.
