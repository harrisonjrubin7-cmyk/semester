# CC-1747 · Measure the shared Search everything true modal

## Summary

The real-browser accessibility smoke now opens the independent shared Search
everything true modal on each of the seven critical journeys at 375 and 1024
pixels. It verifies `aria-modal="true"`, focus entry, forward and reverse focus
containment, serious and critical axe results, Escape close and focus return.
The instrument fails closed when any journey-width combination is missing.

This is a second shared true-modal state, independent of the Quick Add storage
refusal work in blocked PR #1746. Signed-in, error, other-modal, other
interactive, real-device and manual assistive-technology coverage remains
open, and the evidence records preserve those boundaries.

## Environments and tenants affected

None. The change affects automated browser checks and evidence records. It
does not deploy code, publish an artifact, activate a tenant, use institutional
data, change credentials or modify persistent data.

## Risk

The added modal states increase accessibility-sweep time and can reveal a
journey- or viewport-specific focus, modal-state or axe regression. An
unreachable trigger, page error, focus escape, missing modal state or
serious/critical axe finding fails the run rather than silently reducing
coverage.

## Rollback

Revert PR #1747 to restore the prior destination, non-modal-dialog and Quick
Add true-modal sweep. No running environment needs restoration.
