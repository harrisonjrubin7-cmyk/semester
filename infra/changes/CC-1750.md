# CC-1750 · Verify inbound integration webhook envelopes

## Summary

Add a provider-neutral verification seam for inbound integration webhooks. It
bounds the raw body, verifies a timestamped HMAC before parsing, validates a
minimal event envelope, scopes replay claims to a connection and event, and
fails closed when replay protection is unavailable. It does not open a route.

## Environments and tenants affected

None. No endpoint, credential, connection, tenant, database, deployment, or
provider configuration changes. The reference replay store is process-local;
production use requires a durable shared implementation.

## Risk

The main risk is treating a verification primitive as an active integration.
The readiness register therefore remains `building` and explicitly records
that provider schema selection, secret resolution, worker wiring, durable
replay storage, live security evidence, and deployment are still absent.

## Rollback

Revert PR #1750. No provider, data, credential, tenant, or deployment rollback
is required because nothing is activated by this change.
