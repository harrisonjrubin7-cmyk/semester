# CC-1722 · Maintain Workflow Lab dependencies

## Summary

Dependabot receives a dedicated weekly npm updater for the standalone
`workflow-lab/` manifest and lockfile. Minor and patch updates are grouped,
major updates remain isolated, and repository tests fail if the updater loses
its directory, ecosystem, cadence, pull-request bound or grouped update types.

## Environments and tenants affected

None. This change alters candidate update configuration, tests and controlled
documents only. It does not deploy Workflow Lab, activate a tenant, change
credentials, connect an institution or use institutional data.

## Risk

The updater may open future pull requests against a tree with independent CI.
This candidate can validate the configuration and its failure controls, but it
cannot prove a future Dependabot run or a deployed Workflow Lab service.
`video/`, `pipeline/`, `starter/` and the broader `zite/` snapshot remain
outside this updater. TR-15 also remains open for the seven inline Edge
Function handlers that lack executable behavior tests.

## Rollback

Revert PR #1722 to remove the Workflow Lab updater and its repository guard.
No infrastructure state, credential or tenant data needs restoration.

- Local focused controls: 4 files and 52 tests passed. Full application suite:
