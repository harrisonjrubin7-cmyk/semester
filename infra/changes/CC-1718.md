# CC-1718 · Scan every registered destination with axe

## Summary

The production-bundle accessibility smoke now runs axe-core in real Chromium
over the default synthetic state of all 63 registered destinations at 375 CSS
pixels. Planted serious violations prove the instrument before a clean result
is accepted, and an unreachable destination, error boundary, page error or
incomplete count fails the instrument closed. The expanded sweep found and
fixed label-in-name defects in Calendar day cells and equation-piece buttons.

## Environments and tenants affected

None. The change affects candidate source, generated accessibility evidence
documents and repository tests only. It does not deploy, activate a service,
connect an institution, use real institutional data, change credentials or
modify infrastructure.

## Risk

The sweep covers only each destination's default synthetic state at one phone
width. It does not establish accessibility conformance or cover signed-in,
error, modal, tablet, real-device or manual assistive-technology states. The
audit-only browser context bypasses CSP solely to inject axe; shipped response
headers and policy are unchanged.

## Rollback

Revert PR #1718 to restore the prior seven-journey browser smoke and the prior
Calendar and equation accessible names. No infrastructure state, credentials
or tenant data needs restoration; the rollback is a source change only.
