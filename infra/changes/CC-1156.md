# CC-1156 · Offer an off-by-default build flag, VITE_TODAY_SHADOW, to the Pages build

## Summary

`.github/workflows/pages.yml` gains one build input, `VITE_TODAY_SHADOW`, mapped
from a repository variable or secret the way every other `VITE_` setting is,
and the same name is added to the diagnostics step's list (which reports
lengths, never values). The app reads it in `app/src/composition/shadow.ts`;
`app/src/lib/deploy.test.ts` requires every `VITE_` setting the source reads to
be offered here. **Applies nothing**: no Terraform, no permissions, no triggers
and no step is added or changed. Nothing is set today, so the deployed app behaves exactly as it would
otherwise. (The shadow's code does ship, as a lazily loaded chunk that nothing
requests unless the flag is on.)

## Environments and tenants affected

None while the variable is unset, which is how it merges. If an operator later
sets it to `on`, that build runs a comparison of Today beside the Action Center
in the browser and writes differences to the console. It draws nothing, changes
nothing and sends nothing: it makes no request of its own. Any other value is
treated as off.

## Risk

Low. A value other than `on` is ignored. If set, a little extra client work on
Today and console warnings; no tenant can notice anything else. Visible within
an hour in the Pages run's annotation for carried build inputs (name and
length) and in a browser console on the deployed site.

## Rollback

Delete the repository variable `VITE_TODAY_SHADOW` (takes effect on the next
Pages build, about the length of a deploy), or revert the edits to
`pages.yml` (a mapping with its comment, and one name in the diagnostics list). There is no state to unwind: the flag only decides whether code
that is otherwise present but unused runs.

## Evidence

The `pages.yml` diff (three added lines, one changed, no step added or altered); `deploy.test.ts` and `secrets.test.ts` pass
with it (the guards that require the mapping and the `SECRETS.md` row); the
mounted tests under `app/src/components/TodayActionCenter.shadow*.test.tsx`;
see PR #1156.
