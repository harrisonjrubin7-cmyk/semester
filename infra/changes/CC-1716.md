# CC-1716 · Reconcile trust evidence registers

## Summary

The trust registers now count the SQL policy suites and deployed function
directories from the candidate tree, cite the existing legal-hold mechanism,
risk register and repository tabletop, and preserve the boundaries that still
require an authorized target exercise or production-provider export. A
fail-closed test keeps those statements aligned. This change does not alter a
Terraform root or runtime.

## Environments and tenants affected

None. The change affects candidate source, generated trust documents and
repository tests only. It does not deploy, activate a service, connect an
institution, use real institutional data, change credentials or modify
infrastructure.

## Risk

Trust text can overstate repository evidence as an operated target control, or
its counts can drift as new suites and functions are added. The reconciliation
test blocks both failure modes and requires new evidence before a claim can be
raised.

## Rollback

Revert PR #1716 to restore the prior register data and generated documents. No
infrastructure state, credentials or tenant data needs restoration; the
rollback is a source change only.
