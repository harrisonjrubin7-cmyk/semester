# CC-1170 · Introduce infrastructure as code and the pipeline that governs it

## Summary

Adds Terraform for the repository's protections, Supabase settings and the
Vercel edge; the policy that constrains plans and workflows; and the workflows
that plan, apply, detect drift and attest builds. **Applies nothing.** Records
two existing workflow gaps as dated policy exceptions (R-5 `functions.yml`
has no environment gate; R-6 `pages.yml` grants `id-token: write`
workflow-wide), both expiring 2026-12-31.

## Environments and tenants affected

None. No tenant, deploy or production setting changes when this merges.
New workflows run on pull requests touching `infra/`, daily (drift, reports
NOT CHECKED until configured), weekly and on main (supply chain).

## Risk

`supply-chain.yml` and the new workflows have never run on GitHub; the first
runs may need fixes. `supply-chain.yml` will fail a main push on a *critical*
advisory in a production dependency (intended). Visible within minutes in the
Actions tab.

## Rollback

Revert the merge commit. Nothing was applied, so there is no infrastructure
state to unwind.

## Evidence

Terraform 1.15.9 validate and fmt on all three roots; `opa test` 44/44;
`scripts/infra/policy.sh` over every workflow; see PR #1170.
