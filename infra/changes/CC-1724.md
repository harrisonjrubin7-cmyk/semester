# CC-1724 · Maintain Video dependencies

## Summary

Dependabot receives a dedicated weekly npm updater for the standalone
`video/` manifest and lockfile. Minor and patch updates are grouped, major
updates remain isolated, and repository tests fail if the updater loses its
directory, ecosystem, cadence, pull-request bound or grouped update types.

## Environments and tenants affected

None. This change alters candidate update configuration, tests and controlled
documents only. It does not render or publish media, deploy an application,
activate a tenant, change credentials, connect an institution or use
institutional data.

## Risk

The updater may open future pull requests against the Remotion dependency
tree, which is large and can create review noise. The bounded queue, grouped
minor/patch changes, isolated major changes, committed lockfile, CI install and
Video typecheck are the compensating controls. This candidate cannot prove a
future Dependabot run, rendered asset or deployed service. `pipeline/` and the
broader `zite/` snapshot remain outside update automation. TR-15 also remains
open for the seven inline Edge Function handlers that lack executable behavior
tests.

## Rollback

Revert PR #1724 to remove the Video updater and its repository guard. No
infrastructure state, credential, tenant data or rendered media needs
restoration.

## Evidence

- Pull request: https://github.com/harrisonjrubin7-cmyk/semester/pull/1724
- `app/src/lib/dependencyupdates.test.ts` checks the standalone manifest and
  lockfile, holds the updater contract and mutation-tests directory, ecosystem,
  cadence, queue bounds and grouped update-type failures.
- Local focused controls: 4 files and 58 tests passed. Full application suite:
  1,603 files and 25,058 tests passed, with 2 files and 81 tests skipped. A
  clean locked install reported no vulnerabilities, the standalone Video
  package installed from its lockfile and typechecked, app lint passed with the
  existing warning set, Dependabot YAML parsing and `git diff --check` passed.
- Hosted exact-head CI, CodeQL and HawkScan remain required before handoff.
