# CC-1748 · Exercise outcome aggregate cohort and access controls

## Summary

Add a PostgreSQL policy check for the existing `outcome_aggregates` table. The
check exercises the minimum cohort floor and verifies same-school,
cross-school, capability, revocation, anonymous-read, and authenticated-write
boundaries without changing the product schema or runtime.

## Environments and tenants affected

No running environment or tenant is changed by this draft. The proposed change
adds repository and hosted-CI verification only. A matching PostgreSQL 17 CI
run is required because PostgreSQL 17 was unavailable in the local checkout.

## Risk

The check could expose an incorrect policy assumption or make the database
policy gate fail. The fixed minimum cohort threshold remains repository policy,
not tenant-configurable institutional policy, and this change does not address
complementary or differencing suppression.

## Rollback

Revert PR #1748. No deployment, tenant migration, data repair, or provider
rollback is required because this draft does not change a running environment.
