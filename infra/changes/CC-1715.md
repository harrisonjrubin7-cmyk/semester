# CC-1715 · Scope public accessibility claims to repository evidence

## Summary

The public company site and claims register stop asserting a universal
public-site axe result that is not in the repository. They instead name the
six student-app candidate journeys, scheduled Chromium contrast sweep, exact
caption boundary and uncovered public-form assessment boundary that source
tests can verify. A fail-closed test holds those limits. This change does not
alter a Terraform root or runtime.

## Environments and tenants affected

None. The change affects candidate source, public-copy source and repository
tests only. It does not deploy, activate a service, connect an institution,
use real institutional data or change infrastructure.

## Risk

Public copy can become stale as accessibility evidence changes. The source
test intentionally blocks a candidate when the inventory or wording drifts,
so broader claims require new evidence and review instead of passing silently.

## Rollback

Revert PR #1715 to restore the prior copy and register row. No infrastructure
state, credentials or tenant data needs restoration; the rollback is a source
change only.
