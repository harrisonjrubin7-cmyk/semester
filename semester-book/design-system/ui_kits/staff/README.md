# Staff workspaces UI kit

Faculty, Advisor, Registrar and Finance workspaces in one shell — switch roles from the rail. A dark scope bar names the role, tenant and identity on every screen.

- **Faculty** — gradebook with draft → release, regrade decisions. Source: `app/src/components/gradebook/InstructorBook.tsx`.
- **Advisor** — student-controlled meeting shares and authority scope. Source: `AdvisorMeeting.tsx`, `AdvisorSharedView.tsx`.
- **Registrar** — approval requests, capacity, record changes. Source: `enrollment/RegistrarDesk.tsx`, `institutional/OperationsStudio.tsx`.
- **Finance** — student account ledger and two-person requests. Source: `institutional/StudentAccounts.tsx`, `console/Approvals.tsx`.
