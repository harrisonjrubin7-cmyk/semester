4. 90-day roadmap

Days 1–30 · Make the pilot legal to run

  1. Bind cyber + E&O insurance (contract requirement)
  2. EIN, state tax registration, business bank, bookkeeping
  3. Map every DPA/FERPA obligation to a control and an owner
  4. Publish subprocessor list: Vercel, Supabase (+ AI provider, with "no student records" boundary)
  5. Data inventory + data-flow map for student records
  6. Retention + deletion schedule
  7. Test that student records never reach an AI provider; document it

Days 31–60 · Pass the university reviews

  1. Complete HECVAT Full from docs/trust + evidence register
  2. Ship SAML / Shibboleth SSO with the university IdP
  3. VPAT / ACR against WCAG 2.1 AA (use existing a11y tests as evidence)
  4. Incident-response tabletop; record it
  5. Restore-from-backup test; record RTO/RPO
  6. Privacy Policy + Terms reviewed by counsel

Days 61–90 · Launch and prove the pilot

  1. Agree pilot start + renewal decision dates in a mutual action plan
  2. Baseline the success metrics with the champion
  3. Onboarding + support intake with severity levels
  4. Weekly check-in and KPI review
  5. Draft the results deck and annual conversion proposal
