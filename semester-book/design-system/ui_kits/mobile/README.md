# Mobile UI kit

Two phones (Parchment and Ink grounds) with the five canonical destinations from the source — **Today, My Path, Search, Plan, Me** — on the labelled bottom tab bar. Each phone is independently clickable.

Files: `MobileScreens.jsx` (MToday, MPath, MSearch, MPlan, MMe), `MobileApp.jsx` (Phone frame + TabBar).

Note: per docs/BRAND-PLATFORM.md §3, no native iOS/Android binary exists; this is the responsive web app at phone width.
