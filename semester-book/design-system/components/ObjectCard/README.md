The universal decision card: eyebrow → title → provenance → why → metadata → one primary + one quiet secondary.

```jsx
<ObjectCard kind="Assignment" title="Lab report 3" provenance={{origin:"official",by:"BIO 210"}} explanation="Worth 12% of your grade." metadata="Due Thu 9 Oct · 23:59" primary={{label:"Open draft"}} secondary={{label:"View rubric"}} />
```

A card groups a decision, not every paragraph. Never nest cards.
