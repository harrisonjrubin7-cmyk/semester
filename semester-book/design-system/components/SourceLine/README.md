The Source Line — a thin brass/editorial rule from a statement to its source chip; Semester's signature device (docs/BRAND-PLATFORM.md §2.6).

```jsx
<SourceLine source="official" by="Registrar" when="3 Oct"><h2>You need 26 more credits to graduate.</h2></SourceLine>
```

Never decorative: use only where a real source label exists. The chip carries the word; the line is reinforcement.
