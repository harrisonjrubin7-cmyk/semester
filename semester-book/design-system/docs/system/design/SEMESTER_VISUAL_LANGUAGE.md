# Visual language

_Semester design, intelligence, workflow and data system · 2026-10-05 · Source: uploads/expand further on brand identy algorthims workflow.pdf, reconciled with this design system (readme.md, tokens/, components/). Where they differ, this design system wins and the difference is listed._

> Semester should make an institutionally complex world feel personally clear.

**Primary feeling:** a calm, high-trust academic workspace. Not a noisy social app, a legacy portal, a generic corporate dashboard, a childish EdTech product, or a glowing "AI" landing page.

## Color semantics (adopted) and hues (this design system)

| Role | Meaning | Token in this system |
| --- | --- | --- |
| Action / focus / selected | User action, trusted navigation | Semester blue --blue-700 #416180 (light), --blue-400 #94bce3 (dark) |
| Neutral | Calm, focus, readable density | Ink (#090a0e family) chrome, Parchment (#f4f1ea) content, text tokens |
| Success | Completed, healthy, confirmed | Source/status "done" stone hue (ink + hairline + 8% wash) |
| Warning | Needs attention, review, limited confidence, freshness | Attention / review stone hue |
| Critical | Error, security concern, failed, urgent | --status-danger |
| Information | Source, guidance, context | Connected / official source hues |
| Context | Inactive, historical, unavailable | Text secondary / tertiary |

**Rules:** never use status colour as decoration; never show a critical state by colour alone (glyph + words: ◆ ○ ✦ ⇄ ? ! ✓ ⊘).

**Open decision for the founder:** the source PDF proposes indigo/blue-violet as primary and emerald/amber/rose as status hues. This design system uses Semester blue and desaturated stone status hues (readme.md, Visual foundations). The roles above are adopted; the hues are unchanged until you decide otherwise.

## Type

| Role | Use | Token |
| --- | --- | --- |
| Display | Narrative statements, hero | Cinzel (rare) |
| Heading | Screen titles, sections, steps | Barlow Condensed 600 |
| Subheading | Cards, modules | Barlow Condensed |
| Body | Explanation and reading | Barlow 16/1.55 |
| Body small | Metadata, source, freshness | Barlow 13–14 |
| Label | Forms, controls, status | Kicker 10.5 tracked caps |
| Mono | Record, audit, correlation IDs | System mono |

One H1 per page; strict heading order; short student sentences; plain language first; expand acronyms; no long all-caps; tabular figures for money, analytics, schedules; source and freshness readable but secondary.

## Shape, depth, motion

Corners 3/6/10 (moderate, never toy-like). Border and contrast before shadow. Motion 130–280 ms, purposeful, zeroed by reduced motion and calm mode. Illustration only when it clarifies a workflow or reduces anxiety; never filler art.
