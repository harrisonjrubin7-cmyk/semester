# Interaction language

_Semester design, intelligence, workflow and data system · 2026-10-05 · Source: uploads/expand further on brand identy algorthims workflow.pdf, reconciled with this design system (readme.md, tokens/, components/). Where they differ, this design system wins and the difference is listed._

> Semester should make an institutionally complex world feel personally clear.

| Situation | Rule |
| --- | --- |
| Alerts | Only actionable; one primary per view; glyph + words; never colour alone |
| Official data | Source + authority + freshness shown; official items outrank derived ones |
| AI uncertainty | Confidence and limits stated; sources numbered; human or office offered |
| Approvals | Preview first, consequence in words, second approver when consequential, audit before apply |
| Policy restrictions | Say which policy, who owns it, what you can do instead |
| Recovery after errors | Say whether it saved, whether it retries, who can help, reference ID |
| Consent | Recipient, category, purpose, duration, items; revoke always visible |
| Destructive actions | Undo where possible; otherwise a request path; never silent |
