# Brand identity

_Semester design, intelligence, workflow and data system · 2026-10-05 · Source: uploads/expand further on brand identy algorthims workflow.pdf, reconciled with this design system (readme.md, tokens/, components/). Where they differ, this design system wins and the difference is listed._

> Semester should make an institutionally complex world feel personally clear.

## Position

Semester is the education operating system. It turns fragmented academic information, campus systems, learning tools, support workflows, productivity tools and AI into one clear, governed, human-centered environment.

## Emotional outcome by audience

| Audience | Desired feeling |
| --- | --- |
| Student | I know what to do next. |
| Faculty | This helps me teach clearly without adding administrative burden. |
| Advisor | I can support students without chasing information across systems. |
| Registrar | This respects academic authority, auditability and correctness. |
| CIO / security | This is controlled, governable, interoperable and operationally mature. |
| Parent / guardian | I can support without invading the student’s privacy. |
| Employer | This is credible, verified educational evidence — not a scraped profile. |
| Semester operator | I can see, govern, support and improve the platform safely. |

## Personality

- Calm, not sterile
- Intelligent, not patronizing
- Ambitious, not inflated
- Academic, not bureaucratic
- Modern, not trendy for its own sake
- Warm, not childish
- Trustworthy, not vague
- Human-centered, not surveillance-centered
- Powerful, not overwhelming

## Vocabulary

**Use:** path, action, progress, evidence, source, guide, workspace, Course Studio, support, plan, clarity, next step, governed, trusted, connected, official, student-controlled, explainable, accessible, institution-ready.

**Avoid:** disrupt everything, revolutionary AI magic, replace humans, guaranteed outcomes, fully automated advising, perfect personalization, total surveillance, one-click compliance, all-in-one without explanation, enterprise-grade without evidence.
