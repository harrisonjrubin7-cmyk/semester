# Search ranking

_Semester design, intelligence, workflow and data system · 2026-10-05 · Source: uploads/expand further on brand identy algorthims workflow.pdf, reconciled with this design system (readme.md, tokens/, components/). Where they differ, this design system wins and the difference is listed._

> Semester should make an institutionally complex world feel personally clear.

Query → permission filter → tenant/course/context filter → source-authority ranking → freshness ranking → context relevance → result-type diversity → explainable list.

**Result types (authority order):** official institution policy · course content · student-owned content · approved learning source · campus service · support resource · career opportunity · community content · external web · AI-generated answer.

Community content never ranks as more authoritative than official policy.
