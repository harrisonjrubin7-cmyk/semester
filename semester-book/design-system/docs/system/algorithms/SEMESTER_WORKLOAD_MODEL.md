# Workload model

_Semester design, intelligence, workflow and data system · 2026-10-05 · Source: uploads/expand further on brand identy algorthims workflow.pdf, reconciled with this design system (readme.md, tokens/, components/). Where they differ, this design system wins and the difference is listed._

> Semester should make an institutionally complex world feel personally clear.

**Inputs:** credits, meeting schedule, due dates, student time estimates, course workload guidance, assessment dates, conflicts, preferences.

**Outputs:** low / balanced / heavy estimate, peak weeks, conflict warnings, suggested study blocks and sequencing.

**Rules:** guidance, not academic authority; students override their own estimates; no punitive institutional action uses the workload score.
