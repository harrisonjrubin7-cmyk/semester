# Registration readiness

_Semester design, intelligence, workflow and data system · 2026-10-05 · Source: uploads/expand further on brand identy algorthims workflow.pdf, reconciled with this design system (readme.md, tokens/, components/). Where they differ, this design system wins and the difference is listed._

> Semester should make an institutionally complex world feel personally clear.

Readiness = window known + account status known + holds checked + plan exists + prerequisites checked + credit load reviewed + sections selected + alternatives considered + official hand-off available.

**Outputs:** Ready · Almost ready · Blocked · Needs advisor review · Information unavailable.

Every item shows its source, timestamp and action path. Degree scenarios label each line: official requirement, planning estimate, assumption, unavailable data, or confirmation required.
