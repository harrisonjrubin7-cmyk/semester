# Provenance model

_Semester design, intelligence, workflow and data system · 2026-10-05 · Source: uploads/expand further on brand identy algorthims workflow.pdf, reconciled with this design system (readme.md, tokens/, components/). Where they differ, this design system wins and the difference is listed._

> Semester should make an institutionally complex world feel personally clear.

Every node and relationship carries: canonical ID, tenant ID, owner, source authority, source system, source record ID, freshness timestamp, version, classification, consent/grant requirement, role/capability requirement, retention, audit history, export rule, deletion rule, migration source, confidence/verification status.

Derived data and AI outputs record their inputs and version so any value can be traced back to its sources.
