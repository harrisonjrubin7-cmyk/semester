Finance model · pre-revenue to first annual contract

Owner: founder. Status: draft, October 2026. All cost lines are estimates to confirm with quotes, except hosting list prices, which are sourced in §5. Founder salary is $0 in every scenario.

Budget rule: setup must fit the $5,000–$20,000 range. Spend in launch-gate order (insurance, counsel, accessibility, security) before anything else. The pilot fee is the first revenue; nothing below assumes outside money.
