# Corporate governance and legal

_Semester Company OS · 2026-10-05 · Source: uploads/what else on the bussnius and opprations site also.pdf._

> Semester must operate with the same coherence, evidence, reliability and trust it promises to institutions.

**Requires qualified professional review before use.**

| Field | Value |
| --- | --- |
| Mission | Keep the company legally sound, its IP owned, and every contract and obligation tracked. |
| Owner | Founder + fractional counsel |
| Inputs | Formation documents, contracts, policies, counsel advice |
| System of record | Contracts register in /ops legal; corporate records folder |
| KPIs | Contracts with obligations logged; Days to signature; Renewals missed (0) |
| Reports | Monthly legal queue and obligations calendar |
| Meeting cadence | Weekly legal queue review (15 min) |
| Risk controls | No signature without template or counsel redline; IP assignment for every contributor |
| Approval thresholds | Any contract with student data, liability above fees, or non-standard indemnity → counsel |
| Required documents | Operating agreement, IP assignment, NDA, MSA, Order form, DPA, SLA, Terms, Privacy, Acceptable use, Cookie notice, Accessibility statement, Security addendum, Contractor / employee / advisor templates, Marketplace publisher agreement, Trademark register |
| Required integrations | E-sign (embedded), contracts register |
| Current status | docs/legal/ (MSA, order form, DPA, terms, privacy, cookie, accessibility, community, subprocessors) |
| Gaps | SLA, SOW, security addendum, contractor/advisor templates, trademark filing, policy register |
| Priority | P0 |
| Next action | Counsel review of MSA, DPA and order form before pilot launch |

## Workflows

- Request → classify → business owner → legal owner → risk rating → template → redline → approval → signature → obligations extracted → renewal reminder → evidence → amendment/termination
