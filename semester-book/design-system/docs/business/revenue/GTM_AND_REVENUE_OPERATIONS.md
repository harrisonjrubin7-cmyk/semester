# GTM and revenue operations

_Semester business operations · 2026-10-05 · Source: uploads/Show the finance and accounting operations section.pdf. **Accounting, tax, legal, insurance, privacy, security, accessibility and compliance content needs qualified professional review before use.**_

> Every customer promise connects to a financial owner, delivery owner, support process, security/privacy control, product capability and evidence trail.

Two engines: **institutional** (paid pilots → annual contracts → expansion → references) and **student adoption** (value → activation → retained use → institutional proof → referrals).

## Funnel

Target accounts → researched → personalized outreach → replies/referrals → discovery → qualified → role demos → pilot design → security/privacy/procurement → pilot proposal → paid pilot signed → implementation → activation → measured success → annual conversion → expansion/renewal/reference.

## CRM data

**Account:** name, segment, enrollment range, system type, geography, tech stack, priority score, trigger event, champion, economic buyer, technical buyer, security reviewer, procurement contact, stage, estimated ACV, pilot value, annual potential, probability, close date, risks, next step, owner.

**Opportunity:** problem, current workflow, scope, cohort, buyer goals, baseline and success metrics, security requirements, integration needs, terms, mutual action plan, decision process, competitors, objections, win/loss reason.

## Stages and exit criteria

| Stage | Exit criteria |
| --- | --- |
| Target | Account researched and scored |
| Contacted | Relevant stakeholder reached with a personalized message |
| Discovery | Pain, champion, timeline and buyer path documented |
| Qualified | Problem, budget path, decision process, feasibility confirmed |
| Demo | Use case shown to required stakeholders |
| Pilot design | Cohort, scope, baseline, success criteria agreed |
| Procurement/security | Review owners, artifacts, decision path identified |
| Proposal | Price, terms, conversion path, decision date delivered |
| Contracting | Legal/procurement reviewing |
| Closed won: pilot | Executed; kickoff scheduled |
| Pilot active | Cohort launched; metrics measured |
| Conversion | Annual decision in process |
| Closed won: annual | Annual agreement active |
| Expansion | New campus, department, module or users identified |
| Closed lost | Reason, competitor, re-engagement path recorded |
