# Durable unit economics

_Semester platform maturity program · 2026-10-05 · Source: uploads/what else is needed to become the apple google and.pdf. Status is design-stage: nothing is "done" until repo code, tests and release evidence exist._

**Principle:** Semester must become the system people prefer to use every day, the system institutions trust to operate, and the system partners prefer to build on.

## Standard

- Multi-year model, usage and margin, AI cost per workflow, infrastructure unit economics, implementation capacity, support cost, CAC and payback, pilot-to-annual conversion, gross and net retention, expansion, marketplace and partner revenue.
- Pricing governance, discount approvals, quote-to-cash, collections, revenue recognition review, budget and headcount planning, financing strategy, build-vs-buy.
