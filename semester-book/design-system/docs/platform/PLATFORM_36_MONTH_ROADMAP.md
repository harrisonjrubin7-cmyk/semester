# 36-month roadmap

_Semester platform maturity program · 2026-10-05 · Source: uploads/what else is needed to become the apple google and.pdf. Status is design-stage: nothing is "done" until repo code, tests and release evidence exist._

Phases gate on evidence, not dates.

## 0–6 months · Prove the pilot

- Close six launch blockers
- Ship SSO, SIS read sync, Today, registration readiness, governed AI
- Run the Vanderbilt pilot with signed measures
- Monitoring, runbooks, restore drill live

## 6–12 months · Convert and repeat

- Results report and case study
- Annual conversion
- Pilots #2–#3 via the implementation factory
- First engineer and implementation lead

## 12–24 months · Become the operating layer

- Course Studio, advising, registrar desk in production
- Migration factory runs first real domain migration
- SOC 2 readiness; pen test
- Public API beta and first certified partner

## 24–36 months · Platform and ecosystem

- Marketplace with governed installs
- Multi-campus and system offices
- First non-US or K–12 model
- Published outcome research

2. Source authority and freshness on every fact
3. Education graph of relationships, not just records
4. Governed AI that is course-, policy- and source-aware

6. Migration factory that makes replacement safer than staying
7. Reconciliation engine with rollback on every domain
8. Consent and sharing model students trust
9. Tenant isolation proven per table in CI
10. Trust Center with evidence, not claims
11. One design system across product, site and ops
