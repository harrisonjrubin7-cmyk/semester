# 36-month competitive plan

_Semester strategy · 2026-10-05 · Source: uploads/anything else to finish semester and make it the m.pdf. Design-stage evidence only; scores rise with repo, test and release evidence._

> Semester wins when students prefer it daily, institutions trust it operationally, and partners prefer building on it.

## 0–6 months · Prove the pilot

- Close six launch blockers
- Ship SSO, SIS read sync, Today, registration readiness, governed AI
- Run the Vanderbilt pilot with signed measures
- Monitoring, runbooks, restore drill live

## 6–12 months · Convert and repeat

- Results report and case study
- Annual conversion
- Pilots #2–#3 via the implementation factory
- First engineer and implementation lead

## 12–24 months · Become the operating layer

- Course Studio, advising, registrar desk in production
- Migration factory runs first real domain migration
- SOC 2 readiness; pen test
- Public API beta and first certified partner

## 24–36 months · Platform and ecosystem

- Marketplace with governed installs
- Multi-campus and system offices
- First non-US or K–12 model
- Published outcome research

## Growth loop

Pilot → student activation → measured outcomes → annual conversion → expansion → reference → new pipeline → partner interest → ecosystem.
