# Mobile excellence plan

_Semester strategy · 2026-10-05 · Source: uploads/anything else to finish semester and make it the m.pdf. Design-stage evidence only; scores rise with repo, test and release evidence._

> Semester wins when students prefer it daily, institutions trust it operationally, and partners prefer building on it.

- Fast mobile shell
- Offline-safe student-owned workspace
- Push notifications with explicit preference controls
- Deep links from email, calendar, QR codes, announcements
- Native-feeling gestures, never gesture-only critical functions
- Mobile-first Action Center
- Quick capture: tasks, notes, assignments, photos/documents where permitted
- Fast course/resource access; campus QR flows
- Location only with explicit opt-in and clear benefit
- Low-bandwidth and reduced-data modes
- Accessible mobile controls
- Minimum safe offline data; clear sync state and conflict recovery

**Never cache on device unnecessarily:** official grades, financial records, sensitive support details, secrets, privileged institutional data.
