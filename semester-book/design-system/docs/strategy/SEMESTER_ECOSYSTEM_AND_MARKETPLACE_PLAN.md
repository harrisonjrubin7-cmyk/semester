# Ecosystem and marketplace

_Semester strategy · 2026-10-05 · Source: uploads/anything else to finish semester and make it the m.pdf. Design-stage evidence only; scores rise with repo, test and release evidence._

> Semester wins when students prefer it daily, institutions trust it operationally, and partners prefer building on it.

- Developer portal, API standards (docs/platform/API_CONTRACT_STANDARD.md)
- OAuth/OIDC, service accounts, webhooks, event subscriptions, SDKs
- Sandbox tenants and test data
- Integration certification
- Marketplace, partner directory, tenant install approval, data-scope review
- Revenue sharing (12% planning), versioning/deprecation, partner support and incidents

Flywheel: more institutions → partner demand → integrations → platform value → institutional demand. Post-pilot priority (P3 now).
