Operations handbook · on-call, SLOs, monitoring

Owner: founder (on-call lead until the first engineer joins). Status: draft, October 2026. Companion to the runbooks and the support plan.

Sized for a solo founder: narrow pilot hours, S1 always on, and alerts only for things that need a human now. Everything else goes to the daily review.

2. Error budget policy

  • Budget above 50%: normal releases.
  • Budget 0–50%: only fixes and reliability work; no feature releases to the affected service.
  • Budget exhausted: freeze, write a reliability plan, review with the sponsor if a pilot is affected.
