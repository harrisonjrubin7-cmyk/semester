# Semester · Claude Code design-system toolkit

Drop-in files for **harrisonjrubin7-cmyk/semester**, built from the brief in `uploads/provide comand to claud code to excute on this and.pdf` and checked against the repo (`lib/tokenexport.ts`, `docs/DESIGN-TOKENS.md`, `styles/hex.test.ts`, `design-tokens/semester.tokens.json`, `.claude/skills/`).

Copy the tree into the repository root — every path matches the repo layout. The three code files carry a `.txt` suffix so the design-system bundler here ignores them; drop it when copying:

```bash
for f in $(find . -name "*.txt"); do mv "$f" "${f%.txt}"; done
```

| `docs/design-system/SEMESTER-DESIGN-SYSTEM-BASELINE.md` | Phase 1 read-only baseline: architecture, source-of-truth map, strengths, gaps, risks, plan |
| `docs/design-system/README.md` | How to use the skills, Figma MCP, checks and report |
| `CLAUDE.md.design-system-section.md` | Section to append to the existing CLAUDE.md |
| `.claude/skills/create-semester-component/SKILL.md` | Spec-first shared component; rejects one-off wrappers |
| `.github/ci-design-system-steps.yml` | Three steps for the existing `ci.yml` build job + report artifact |
| `gitignore.addition` | `app/reports/` |

| `app/scripts/design-system-report.mjs` | Markdown report for CI (`--out`), exits with the audit status |
