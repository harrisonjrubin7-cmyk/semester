# Semester Institution

The university's operational command center for staff at a Semester customer institution: chairs, registrars, department administrators and institution administrators.

It is a front door, not a second system. It uses the same tested workflows and data as the main Semester app (decision C23, option a): new course section requests (department → chair → registrar → canonical section → instructor → reconciliation receipt), registration holds, aggregate analytics with small-count suppression, members, source-system connections and the audit log. Each person sees only what their role at their institution allows; the server enforces it.
