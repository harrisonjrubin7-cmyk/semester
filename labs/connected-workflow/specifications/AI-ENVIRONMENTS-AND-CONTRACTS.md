# AI, environments and contracts
Six checks: verified identity/purpose; object permission/policy; minimum necessary classification/retrieval; provider/region/retention/tool egress allowlist; source/freshness/injection/output validation; labelled answer and separately authorized human-confirmed action. Protected records excluded from model-provider payloads by default; no claim of universal enforcement until network boundary tests, logs and qualified review prove it.
Local/preview synthetic-only by default; staging and production require separate approved projects/credentials/storage/callbacks/queues. No production copy into lower environments. 'Data never crosses' is a control objective requiring actual infrastructure/egress verification, not evidence supplied here.
Front end offers permitted actions; middleware verifies context; API makes policy/current-state decisions; database enforces tenant/object integrity. UI role prop never grants access.
Command: capability/command/object/expectedVersion/idempotency/purpose/payload/approval. Event: eventId/tenant/object/version/type/time/correlation/source. Receipt: committed authority fact and separately named projection state. Projections can lag without requiring confirmed actions to be repeated.
Finance: native intents/plans/invoices/ledger/refund workflow; regulated rail adapter handles card/settlement. No PAN/CVV. Currency-balanced double-entry, immutable reversal and signed/deduplicated provider events. No finance action implemented by this lab.
