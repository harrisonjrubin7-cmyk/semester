# Connected screen acceptance contracts
Student shell: Ink rail, tenant/term context, page head, Today cards + aside, source line, first meaningful action, accessible screen switching. Private drafts and what-if remain private.
Course Studio: week plan + student preview; assignment/rubric/AI rule + accessibility publication gate; graded vs released states. Lab implements submission/draft grading/controlled release, not authoring or accessibility certification.
Registrar: cohort filters, holds by owning office, missing/stale evidence, reasoned exceptions, approval trail, reconciliation. Clearing one hold never asserts whole readiness.
Operations Inbox: My Work/team tabs, type filters, due-time SLA (not invented targets), detail, consequence/recovery preview, independent approver, receipt. Business-only defaults.
Institution: environment bar, Ink rail, tenant/roles/policies/integrations/audit, table with caption/row headers and decision trail. Server authority for each action.
Device privacy: why/when/fallback/retained-data pre-prompt before OS ask; Not now preserves fallback; blocked vs denied vs managed; sessions/delegations revoke with scope/expiry and server enforcement.
Privacy center: AI categories, sharing, delegations, sessions, history, export/delete with retention exceptions. These workflows are specification-only in this increment.
Role onboarding: 13 proposed role templates use identity→connection→privacy→AI choice→first home; canonical role reconciliation required. Lab supports five synthetic roles only.
Role workspace: one shell, role-specific first action, tiles/queue/capabilities and 'cannot see'; role prop presentation-only.
Data components: metric kind/period/denominator/source/age; unavailable not0; pattern-encoded charts with hidden table. Tables caption/row headers/sort semantics. All seven region states.
Governance/overlays: lifecycle words, reasons, blocked self-approval, focus trap/return/Escape, reduced motion, pauseable Undo≥6s for reversible work. No declared accessibility compliance from component presence.
All requested brand/type/layout tokens reuse the verified design-system baseline; no invented custom fonts, logo endorsements or measured compliance values.
