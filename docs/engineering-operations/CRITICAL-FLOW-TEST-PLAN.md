## Required matrix

For each in-scope flow run authorized and unauthorized roles; first-run/empty, populated, loading/saving, success, stale, offline/degraded, restricted, validation/error, retry, destructive confirmation and recovered/resumed states. Cover phone, desktop, keyboard, screen reader, 200–400% zoom, reduced motion, large/long content and supported browsers. For server boundaries test cross-tenant access, replay/duplicate, rate limit, timeout, unsafe input/redirect, kill switch, audit and deletion/offboarding.

## Acceptance

Record exact revision/environment/configuration, participant/role, fixtures/data authority, steps, expected/observed outcome, screenshots/logs with redaction, defects/severity/owner, retest and decision.
