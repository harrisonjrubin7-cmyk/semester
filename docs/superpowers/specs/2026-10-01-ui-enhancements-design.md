# Semester UI enhancement completion design

The attached UI enhancement PDF is the authority for twenty improvements. Preserve existing real-data workflows and the calm shared shell. Extend the current implementation rather than replacing the application.

## Changes
1. Route exact natural-language navigation commands through the existing command overlay; open the appropriate workflow, never execute a consequential action. Unknown phrases remain searches. Capture commands still open a reviewable draft.
2. Add an accessibility disclosure to the shared continuity strip using existing persisted look preferences: text size, spacing, reduced motion, plain language and Focus View. Keep full settings reachable.
3. Add verified source excerpts, location and owner to the existing source drawer, populate deadline excerpts from the already verified item quote, and never construct citations when absent.
4. Give the existing decision comparison table table/card/summary views. Preserve unknown values, user option order and official next steps in all views.
5. Audit all twenty PDF items with concrete implementation paths and remaining scope. Retain existing launch gates until real evidence satisfies them.

## Verification
Use unit and rendered interaction tests, the production build, the repository test suite and browser golden-path smoke where the environment supports it. Production access, institutional approvals and reviewer sign-offs are external acceptance evidence and cannot be manufactured by code.

## Constraints
No new product dependency. No automatic sharing, registration or external message sending. No fabricated go status. Personal local use and institutional production acceptance are distinct verification targets.
