# Keyboard shortcuts

> **Type:** help · **Audience:** students · **Owner:** `product` · **Truth:** held · **Reviewed:** 2026-10-04 · **Held by:** `app/src/lib/docs/help.test.ts`

Use this page to move around the app from a keyboard; stop reading if you use a phone, where the shortcuts do not apply.

## What you need first

- A keyboard and a screen where no field has the cursor. Shortcuts do nothing while you are typing.

## Steps

1. Click an empty part of the page, or press `Esc` to leave a field.
2. Press `?` to open the list of shortcuts. Press `?` or `Esc` to close it.
3. Press a key from the table.

| Key | What it does |
| --- | --- |
| `T` | Today |
| `C` | Courses |
| `S` | Study |
| `K` | The calendar |
| `M` | Mine — your actions, notes and files |
| `A` | Ask about this screen |
| `N` | Add a course from a syllabus |
| `Q` | Add something in one line |
| `B` | Bookmark the tab you are on |
| `/` | Search everything |
| `Esc` | Back |
| `?` | This list |
| `⌘K / Ctrl+K` | Search and quick actions |

## What you will see

- `M` opens the screen titled **Personal**. The list calls it "Mine".
- `/` puts the cursor in the search field when your layout draws one, and opens the search palette over the screen when it does not.
- `A` opens the assistant for the screen you are on. It does not leave the screen.
- `⌘K` on a Mac or `Ctrl+K` elsewhere opens the same search.

## If it does not work

- Nothing happens: check that no field has the cursor. Press `Esc` first.
- Nothing happens while a dialog is open. The dialog has claimed the page. Close it first.
- A key with `⌘` or `Ctrl` does what your browser does. The app takes none of them except `⌘K / Ctrl+K`.

## Where your data goes

A shortcut sends nothing by itself. It moves you around the app on your device.
