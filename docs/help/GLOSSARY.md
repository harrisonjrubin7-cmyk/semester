# Glossary

> **Type:** reference · **Audience:** students, families · **Owner:** `product` · **Truth:** held · **Reviewed:** 2026-10-04 · **Held by:** `app/src/lib/docs/help.test.ts`

The words Semester uses on screen, spelled as the app spells them; stop reading if you want steps, which are in the [help index](README.md).

Each term below appears in the app's own text. A test checks that every term exists in the source, so a renamed term fails the build. Capitals in the app are styling only: the words are written in sentence case.

## Your courses and your time

| Term | What it means in Semester |
| --- | --- |
| **Course** | One class you are enrolled in. It holds a syllabus, deadlines, readings and a study guide. |
| **Action** | A concrete next step. The ones you add yourself are your own actions. |
| **Deadline** | The last time something can be done. |
| **Today** | The screen showing what is due, what is next, tonight's hours and the week ahead. |
| **Next best step** | The one action Today puts first, with the reason it is first. |
| **Hours** | A tab on Today. It shows tonight's hours. |
| **Done** | A tab on Today. It lists what you finished, so a day leaves a trace. |
| **Calendar** | Classes and deadlines by day, three days, month or semester. |
| **Personal** | Your own actions, appointments, notes, places and files. The keyboard list calls it "Mine". |
| **Exam radar** | The count of days to your next exam on the Study screen. |
| **Exam runway** | The weeks before an exam, counted backwards from it. |
| **Catching up** | What has gone by, and what still fits. |
| **Quiet hours** | One window in which reminders stay silent. |

## Studying

| Term | What it means in Semester |
| --- | --- |
| **Study** | The screen where you pick a course and a way through it. |
| **Unit** | One section of a course guide. |
| **Cards** | Question-and-answer cards, drilled one unit at a time or all at once. |
| **Field guide** | A written guide to the course, section by section. |
| **Cram** | A short revision sheet for a unit. |
| **Weakest unit** | The unit the Cards page says to drill first, from your answers so far. |
| **Unseen** | A card you have not answered yet. |
| **Create study guide** | The button that makes a guide from the source text you tick. |

## Where a fact came from

| Term | What it means in Semester |
| --- | --- |
| **Student entered** | You typed it. Semester has not checked it with your institution. |
| **Imported** | Copied in from a file or feed. |
| **Estimated** | Worked out by Semester from what it knows. It is not an official figure. |
| **Needs review** | Something looks wrong or out of date. |
| **Institution verified** | Confirmed by the institution's own system. |

## Your data and the assistant

| Term | What it means in Semester |
| --- | --- |
| **On this device only** | The status when nothing can leave the device. |
| **Not signed in** | The status when you have no account. Everything stays on this device. |
| **Synced** | The status when your account holds the same semester as this device. |
| **Queued to sync** | Changes are saved on this device and wait for a connection. |
| **Take it with you** | The screen for backups, exports and earlier copies. |
| **Go back a day** | The section that restores an earlier copy the app took on this device. |
| **Semester Intelligence** | The settings for the AI features. Its screen is titled "Intelligence". |
| **Ask Semester** | The conversation with the assistant. |
| "Needs Claude" | The notice that a feature needs an AI key. It names the provider, and Claude is the default. |
| **Recovery** | The screen for when a plan changes or something goes missing. |

## Looks and layout

| Term | What it means in Semester |
| --- | --- |
| **Ground** | The background the whole app is drawn on. |
| **Accent** | The one colour used for what you can act on. |
| **Navigation** | The way you move through the app: a tab bar, one feed, a home screen, shelves, a workspace or study guides. |
| **Layout** | How a screen is arranged: Drawn, Grouped or Soft. |

## People and roles

| Term | What it means in Semester |
| --- | --- |
| **Family** | The screen where you decide what one other person would see, item by item. |
| **Authorized family** | A role choice. It changes the words and screens in the app and does not grant access to any student's records. |
| **Parent or payer** | A role choice with the same limit. |
| **Teaching** | A role choice for an instructor. It does not grant publishing, rosters or grading. |
