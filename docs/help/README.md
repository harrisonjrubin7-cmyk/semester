# Help for people who use Semester

> **Type:** reference · **Audience:** students, families · **Owner:** `product` · **Truth:** held · **Reviewed:** 2026-10-04 · **Held by:** `app/src/lib/docs/help.test.ts`

The index of the help pages, written for the people who open the app; stop reading if you run a school or build the product, because other sets cover that.

Each page says what you need first, gives numbered steps in the app's own words, says what you will see, and says what to do if it does not work. A test reads every page against the app's source, so a renamed button fails the build. Pages about things that are only partly available say so in the first screen.
