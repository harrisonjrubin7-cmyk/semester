# Customer-discovery and pilot evidence log

Operating artifact from the readiness synthesis of 30 Sep 2026. **This file holds no findings.** It is the shape an entry takes, so that what is learned from a real student, adviser or administrator is recorded the same way and can be checked by someone else. Nothing below is a result, a target reached, or a claim.

## Rules

1. **No real student data.** Record roles and cohorts, never names, addresses, ID numbers or quotations that identify a person. If a person asks not to be recorded, they are not.
2. **A number is a target until it is measured.** Targets are labelled `TARGET`; measured values `MEASURED` with a date and a method. A target is never quoted outside this file as if it were achieved.
3. **One question per entry**, one source per entry. "Students like it" is not an entry.
4. **Each entry names who checked it** (someone other than the recorder) before it feeds a decision.
5. Counsel decides whether interviews with students need consent or institutional review before the first one is held. **Not decided.**

## Entry

| Field | Meaning |
| --- | --- |
| Id | `DE-001`, in order |
| Date | ISO date of the conversation or measurement |
| Cohort / role | e.g. "second-year students, one campus" — never a name |
| Question | The single thing asked or measured |
| What was said or measured | Paraphrase or number; `TARGET` or `MEASURED` |
| Method | Interview, survey, log, observation |
| Sample | How many, and how chosen (and what that leaves out) |
| Decision it feeds | Which release gate, module or price it bears on |
| Checked by / date | Second person |
