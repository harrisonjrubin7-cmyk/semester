# Pilot closeout package

A closeout is a decision record, not a slide deck. Each file connects evidence to the next decision. Files 01–10 are templates until the pilot's observation window ends; each file names its evidence source and stays `pending` until that evidence exists.

| File | Holds | Evidence source |
| --- | --- | --- |
| 00-executive-decision-record.md | Decision, hard stops, signers | Files 01–10 |
| 01-approved-scope-and-changes.md | Scope as approved, and every change since | Change control log |
| 02-student-and-staff-outcomes.md | Comprehension, next-action, staff routing | Measurement plan |
| 03-source-integrity-and-reconciliation.md | Freshness distribution, case age, mapping errors | Reconciliation cases |
| 04-support-and-operational-health.md | Queue volume, acknowledgement time, repeat categories | Hypercare daily log |
| 05-accessibility-and-trust-findings.md | Accessibility findings, trust signals | Drill register, support themes |
| 06-security-and-privacy-review.md | Access reviews, drill results, privacy findings | Drill register, access register |
| 07-open-risks-and-remediation-plan.md | Open risks with owner and due date | Risk register |
| 08-expansion-options-and-costs.md | Options and their costs | Commercial terms record (owner to name; not yet in the registry) |
| 09-renewal-or-conclusion-decision.md | Renewal or conclusion, with reasons | File 00 |
| 10-retention-and-offboarding-plan.md | Data retention and offboarding steps | Retention policy |

Every file: a named owner, the evidence it cites, and a date. No file asserts a result that the evidence does not show.
