## D-1542 · Registration readiness is a derived planning state, never an enrollment record

**Decided 2026-10-13.** Semester represents registration readiness as a derived, source-aware planning state. It does not represent a student as enrolled unless an authorized institutional source returns an enrollment outcome.

Why: readiness combines inputs that can be stale, incomplete, or pending human review. Enrollment is an official institutional decision, and presenting readiness as enrollment would make a planning aid look like a registrar record.

Consequences: receipts, UI copy, APIs, events, support macros, and training must distinguish readiness from enrollment. The audit trail records each readiness evaluation as a planning result.

Evidence required before this decision is relied on in a pilot: source-freshness tests (AT-RDY-002), institutional copy approval, a reconciliation drill, and a student journey test (JNY-RDY-001). None of these exists yet; see `docs/governance/readiness/README.md`.

Not done: this record does not accept ADR-014 in the ADR program. The enrollment wording in the UI and receipts is not audited here.
