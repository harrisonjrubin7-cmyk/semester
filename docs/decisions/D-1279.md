## D-1279 · The shared key serves a school's student only when the school has turned AI on

**Decided 2026-10-05**, on the owner's answer to the question left open in D-1251: yes, a school's students should be served by the shared key when their school has turned AI on.

**What.** `supabase/functions/claude/index.ts` no longer refuses every account that belongs to a school. An account with no school is served as before. A school's account is served only if, read live: the school's `semester_intelligence` feature is `production`; the account is in the release cohort if one is named; it has exactly one active `institution_membership` with a permitted role; the school's `ai_policy` allows `anthropic`; its monthly budget is set and `ai_usage_spent` is under it; and the school's own `kill.ai_generation` row is not engaged. Anything unreadable, missing or malformed is a refusal: 403 (`tenant_managed_account`, `tenant_budget`) or 503. All of it is asked before the plan is read or a call is counted (`supabase/functions/_shared/tenantai.ts`, `app/src/lib/tenantai.test.ts`).

**Why these conditions.** They are the parts of the gateway's policy (`app/server/institution/intelligence-repository.ts`) that decide whether a school's student may be served at all. `preview` and `sandbox` states are not read as a launch to students on a shared key; a feature that names no permitted role permits nobody.

**Not done.**
- The school's meter is read, not drawn down. Shared-key spend is metered per account (`add_spend`), so a school's budget is not charged by these calls. A decision is needed before the shared key is activated for any school.
- First sign-in is not bound to a membership (`bind_institution_sso_membership`); an account with no membership row is refused.
- The gateway's per-request modes, models and course sources are not copied.
- The function is behind the provider-activation gate (`D-1031`), so it serves nobody today. It is not deployed and not run on a Deno runtime.

**Seen red.** The structural tests fail against the previous function (3 failures) and pass with this one. The decision test caught `Number(null) === 0` reading an unknown spend as zero spent; fixed.
