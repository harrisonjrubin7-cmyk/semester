## D-1705 · The Command Center is the existing operations console, extended workspace by workspace, never a second app

**Decided 2026-10-26.** Harrison's Command Center brief, which covers the company, institution and personal scopes and six navigation groups, is built inside the existing console at `#/console`. That console already has the gate, the capability registry, the approvals that the database enforces, and hash-chained audit. Each new area becomes a registered workspace with its own capability and its own server reader. The navigation names in the brief are treated as proposals. The first step is **My work**. It is a queue over readers that already exist, it adds no new write path, and its total is shown as a floor whenever a granted source cannot be read.

Not done: everything else in the brief is in `docs/command-center/CURRENT-STATE-AND-PLAN.md`:
- the release-incident and privacy queue sources;
- pilots and implementations (slice B);
- product, engineering and reliability views through a server-side GitHub adapter (slice C);
- the business and governance workspaces (slice D);
- a decision on operator-wide search scope.

Nothing is deployed.
