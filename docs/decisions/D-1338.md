## D-1338 · The access saga and the component definition exist as tested code with no caller; the policy language, API contracts and tables are not adopted

**Decided 6 Oct 2026**, on the owner's instruction to execute eleven control-plane PDFs. The full account, the PDF-by-PDF disposition and backlog items C-1 to C-6 are in [`docs/master/SEMESTER_NATIVE_PDF_DELTA.md`](../master/SEMESTER_NATIVE_PDF_DELTA.md).

- **What was decided.** `packages/institution/src/access-saga.ts` holds the access saga: a 15-state machine, and a runner that advances one saga one step against a `Store` and `Services` it does not implement. `registry.ts` holds the component definition validator and the cross-definition checks, with two JSON Schemas in `docs/control-plane/` held to the code by tests. **Nothing calls either**: no route, no table, no worker.
- **Four rules built in.** A grant is cut only from a fresh evaluation (a finished step-up or approval goes back to validation; an install found absent goes back to evaluation at the next generation). `ACTIVE` is reached only through verification. An install of unknown outcome is reconciled, never assumed failed. Cleanup is confirmed on the administrator and the enforcement point separately, and a grant that may exist without a recorded id is revoked by saga and generation.
- **The PDFs disagree with each other.** Four phrasings of the saga were supplied; the machine follows the ninth PDF's graph. Where a later one found a real gap (the orphaned grant, one-sided cleanup, a late install resurrecting access) the gap was closed and tested; renamings and a reducer/runner split were not adopted.
- **Not adopted.** Rego: ADR 0007 keeps policy in TypeScript until a tenant must author it without a deploy. OpenAPI and AsyncAPI: nothing here validates them, and an unvalidated contract file reads as a contract. A trust score: no formula and no signal source exist. Database tables: wait on C-1 and C-2.
- **Held by.** 50 saga tests and 16 registry tests. Twenty-one deliberate breakages each turned red the test written for it; one survived the first run and now has a test.
- **Not done.** Persistence, the store-side failure rehearsals, the revocation barrier at a real enforcement point, and the `registration.*` rules in `policy.ts` the saga would need before `decide` could ever allow one.
