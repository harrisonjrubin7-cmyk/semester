## D-1502 · The semester-core workflows live in app/src/lib/core, and their equity reviews stay drafts until the named reviewer reads them

**Superseded by [`D-1648`](D-1648.md)** (2026-10-19): `lib/core` was removed because nothing called it and six of its nine modules repeat existing repo logic.

**Decided 2026-10-12.**

The handoff's `semester-core` modules are pure TypeScript with no I/O. They are
placed in `app/src/lib/core/`, the folder the handoff's own README names, rather
than in a new workspace package. A package would add a build and a publish step
to a module that nothing outside the app uses yet.

Two ranking functions in the port, `rank` (which copy of a fact is shown) and
`order` (the order of a student's next actions), are consequential, so the equity
gate requires a review for each. The reviews are written from the code and carry
a finding that the named reviewer has not read them. The gate passes on the
drafts, but they are not reviews until the reviewer reads them, changes what is
wrong, and removes that finding.

Not done here: wiring the modules into screens, the choice of app target (Vite
with a `web/` Next.js app, or Next.js throughout), and the reconciliation of the
handoff's workspace and screen counts. The coverage matrix is in
`docs/ecosystem/`.
