## D-1648 · The Vite app and its server stay the app target, and the unused lib/core port is removed

**Decided 2026-10-19.** Supersedes [`D-1502`](D-1502.md).

**App target.** The founder approved the stream 00 baseline and chose the Vite
app. `app/` stays Vite + React. The platform API stays where it already is:
`app/server` and `app/api` (Vercel functions), Supabase RPCs and the edge
functions. No `web/` Next.js app is created. BUILD.md §2 offered one only to host
the handoff's Next.js API routes. Stream 01's diff
([`../execute/01-platform-core-diff.md`](../execute/01-platform-core-diff.md))
marked those routes `drop`, because the gateway under `app/server` already does
their job. Adding Next.js now would create a second API beside the first. The
stream 00 baseline was already recorded in [`D-1287`](D-1287.md). The founder's
approval confirms it.

**lib/core.** D-1502 put the handoff's nine `semester-core` modules in
`app/src/lib/core/`. Nothing imported them. Stream 01's diff had already said that
a separate `lib/core` "conflicts with the flat lib layout". A read of each module
against the repo found that six of them repeat logic the repo already has:

| Module | Already in the repo |
| --- | --- |
| `nextaction.ts` (`order`, `score`) | `lib/actions.ts` `score`/`rank`, `lib/nextstep.ts` |
| `provenance.ts` (`LADDER`, `rank`, `effectiveOrigin`, `ageLabel`) | `lib/where.ts` `TRUST`, `whereFeed`; `lib/source.ts` `freshnessState`, `freshnessLine` |
| `access.ts` | `private.has_capability`, break-glass SQL, `packages/institution/src/policy.ts` |
| `approvals.ts` | `public.decide_approval` and `console-approvals.check.sql` |
| `aigateway.ts` | `app/server/institution/intelligence.ts`, `ai-data-class.ts`. Note that core drops student records and sends the rest, while the repo refuses the whole request, so core contradicts repo policy |
| `pilot.ts` | `lib/readiness.ts`, the SQL go-live gates |

`scoring.ts` grades the design-tool workflow lab and is out of product scope
(stream 01 diff, `drop`). The whole folder is removed, along with the two draft
equity reviews for `lib/core/provenance.ts#rank` and `lib/core/nextaction.ts#order`.
Those were never read by the reviewer, and the functions they reviewed no longer
exist.

**Kept as backlog, not code.** Four behaviours in the port have no counterpart in
the repo. Each should be written beside the first screen that needs it, with its
test and, where it ranks, its equity review:

1. Picking one copy when sources disagree and flagging the disagreement
   ("2 sources disagree"). It belongs in `lib/where.ts` on `TRUST`, not on a
   second ladder.
2. Projection lag states (live, recent, delayed, failed, rebuilding) and the rule
   that disables destructive actions while a projection is failed or rebuilding.
3. A rollback timeout for optimistic writes. `packages/offline-sync` confirms by
   version, but it never gives up.
4. One classifier for how hard an action is to take (undo, preview,
   review-confirm, two-person). Today `lib/undo.ts` and `lib/ops/console.ts`
   each answer part of it.

The original handoff files remain in `docs/handoff/semester-core/`.

Not done here: building any of the four, the design-archive location, and
reconciling the handoff's workspace and screen counts.
