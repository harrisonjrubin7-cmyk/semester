## D-1537 · The registration-readiness pilot artifacts live in this repository, under `docs/pilot/registration-readiness/`

**Decided 2026-10-13.**

The pilot-package source describes a separate `semester-platform/` tree (Next.js, Supabase, `apps/`, `packages/`). This repository already holds the readiness code under `app/server/institution/` and `app/src/components/`, so a second tree would duplicate it and split its owners.

The artifacts are therefore written here, in `docs/pilot/registration-readiness/`, and the README records which of the 30 exist and which are open.

Not done: the artifacts are not reconciled with the existing readiness code; the feature flag `registration_readiness_v1` is not wired into app code; no production or staging deployment has been made. Go/no-go is `pending` until named owners and signed approvals exist.
