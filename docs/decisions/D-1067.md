## D-1067 · Keep decision support transparent and student-owned

**Decided 1 October 2026.**

The executive-function workflow lives in Pathway, using an account-scoped device library and the existing private workspace backup. The global quick-add panel captures context into the same inbox. Unknown fit evidence is excluded from weighted calculations and evidence coverage is displayed separately. Importance remains visible and editable; no option is automatically chosen.

Assumption edits preview the student's recorded impact links and invalidate source checks while preserving fit judgments. Source checks expire after thirty days. Institution-owned inputs cannot be overwritten through the editor. Advisor exports require a content preview and exclude private reflections and journal history.

The delivery document records the implemented features, activation requirements, and validation limits.

**Extended 1 October 2026.** Explicit cloud synchronization uses owner RLS and optimistic revisions; each replacement is reviewed with a device backup. Source/model context is previewed, reflections stay private, semantic hits require authorized source IDs and exact excerpts, and institutional AI retains the approved-source gateway. Institution aggregates expose counts only after active-member consent and a ten-person threshold. Calendar and connected-provider changes require their own explicit controls. Source availability checks never certify institutional policy. See the delivery document for activation and validation limits.
