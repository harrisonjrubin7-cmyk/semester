## D-1170 · Production infrastructure is changed only by a gated pipeline, and drift is never closed silently

**Decided 2026-10-04.** (Proposed by the DevSecOps seat; the maintainer accepts by merging.)

Infrastructure is defined in `infra/` as Terraform, constrained by Rego
policy, and changed only by `infra-apply.yml`: `main` only, an approved
`CC-<pr>` record, a required reviewer, the exact hashed plan, and a converge
check. `drift.yml` compares the live system daily; drift is closed by
reverting through the pipeline or by adopting it through a pull request with an
`emergency` record, never by editing the issue closed. Policy findings on
files older than the policy are recorded as dated exceptions (an expired one is
itself a violation) instead of being fixed blind or ignored.

**Not done:** nothing is applied; there is no state store, credential or
staging project (`docs/infrastructure/ACTIVATION.md`). Four-eyes review is not
possible with one maintainer (R-1). Attestation covers the CI bundle, not the
Pages bytes (R-3). Backups remain unverified (R-7). Response times for
vulnerabilities are the existing D-124 ones, unchanged.
