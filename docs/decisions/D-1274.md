## D-1274 · Make the existing token pipeline enforceable for agents and CI: one audit, two ratcheting raw-value ledgers, Figma as a read-only input

**Decided 2026-10-05.** `look.ts` → `tokens.css` → `tokenexport.ts` → `semester.tokens.json` stays the only token pipeline; the JSON is generated and never edited, and `CLAUDE.md` now says so with the order in which files win, the UI, accessibility, responsive, state and Figma rules, and the three skills that apply them. Two sessions built the audit at once. `design-system-audit.mjs` (landed first) stays as the audit: hex against `hex.test.ts`, undefined custom properties, export sync and the Figma mapping table. Its `.tsx` raw-value ratchet had no baseline file and so only warned; `app/design-system-baseline.json` is now written and enforced. What it does not read — stylesheets, and colour functions in `.tsx` — is `design-system:css` against `src/styles/rawbudget.ts`, a per-file ledger that may shrink and may not grow. The two never count the same value, so none sits on two lists. A custom-property definition is a token being decided and is not counted.

Figma is an input for approved visual intent, read through the remote MCP server named in `.mcp.json` (no credential; each developer signs in with `/mcp`). Mappings live in `docs/design-system/FIGMA-MAPPING.md`; the audit fails a path that does not resolve in the export. No Figma file is connected, so every Figma name there is a proposal. No Figma write is automated. CI runs `design-system:check`, then the report, and uploads it, with no credentials.

Not decided here and not done: fixing the carried raw values; fetched Figma names or Code Connect; visual regression in CI; correcting the 760/1180 breakpoints in `docs/design/GOVERNANCE.md` (`lib/media.ts` says 600/840/1200/1600). Tailwind, Storybook, pnpm and a `packages/ui` or `packages/tokens` were considered from the strategy document and rejected: none exists here and each would be a second source of truth. A JSON mapping manifest and a second report renderer were written and dropped in favour of the ones already on main.
