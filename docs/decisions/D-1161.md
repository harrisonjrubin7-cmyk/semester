## D-1161 · Extend the existing security policies into one operating program, and fix the gaps that can be proved, not write ten more policies

**Decided 2026-10-04 (proposal status: the security seat confirms each finding's severity; until then no clock runs).** A read of `main` found a policy for each of the ten security-program areas already in the repository. The program is therefore the index and the operating layer in [`docs/security/`](../security/SECURITY-PROGRAM.md): a findings register with the clock `SECURITY.md` already defines, a tenant-isolation test catalogue (TI-01 to TI-12), a detection catalogue (DET-01 to DET-16), a per-change threat record, owners, and a 30/60/90-day plan. Three gaps small enough to prove were fixed in the same pull request: `supabase/check.sh` now fails a suite that prints no `ok` notice (an empty suite or missing `\ir` target used to read as green); the full-tree gitleaks binary is verified against its published SHA-256; and a CodeQL workflow adds static analysis, running only where code scanning is available.

The proposed severity model keeps `SECURITY.md`'s four rows unchanged and adds, as a proposal only, a CVSS v4.0 starting point with two adjustment rules (§6 of the program). Nothing here is a claim of SOC 2, ISO/IEC 27001, a completed HECVAT, an independent penetration test or a signed data-processing agreement; `app/src/lib/securityprogram.test.ts` fails if the documents affirm one.

Not decided here and not done: turning `schools.enforce_membership` on for any school (F-01); routing any alert to a person (F-08); applying the branch ruleset (F-09); moving provider tokens off `localStorage` (F-02); whether signing out erases local data (F-03, a product decision); removing the phone factor from privileged freshness; the CVSS adjustment rules; choosing a log sink or SIEM; and every legal conclusion — notification duties, safe-harbour wording, data-processing terms — which stays with qualified counsel. CodeQL has not run: it needs `CODEQL_ENABLED=true` or a public repository.
