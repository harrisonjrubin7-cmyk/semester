## D-1177 · A connector augments a native capability and is safe to turn off, and the framework pieces that were missing are libraries first

**Decided 2026-10-04.** Every provider domain must name the native Semester capability it augments and the native screen that still does the job with the connector off; a connector is never the only way a capability works. This is enforced by types (`NATIVE_FALLBACK` is exhaustive over `ProviderDomain`), by a test against the real screen table, by the degraded experience always returning the native route, and by a `disable_safe` check in the contract harness that every live adapter must pass. See [`INTEGRATION-CONTROL-PLANE.md`](../INTEGRATION-CONTROL-PLANE.md).

The parts the control plane lacked were added as pure, tested libraries beside the existing pipeline, not as a second control plane: credential leases, the OAuth/OIDC token lifecycle, webhook ingress, a per-connection rate guard with a circuit breaker, a health model with reasons, a parallel-run assessor with a cutover gate, and the conformance harness. Choices worth keeping:

- A dead OAuth grant is never retried; the connection stops and asks for reauthorization.
- Only retryable provider failures open the breaker. A permanent failure is a fault in our configuration and must not hide behind "provider unavailable".
- A credential lease is audited before it is issued, and no audit record means no lease.
- A cutover is requested on evidence plus two independent sign-offs in different roles, never by the proposer, and the assessor never performs it.
- "Needs reauthorization" is a reason under `error`, not a new connection status, so the database vocabulary is unchanged.

Not decided here and not done: no live adapter is registered and no provider endpoint has been exercised; the new libraries are not yet wired into `worker.ts`, and there is no webhook HTTP route (both are the first follow-up); email is a student-credential capability and reporting is not modelled, and making either a tenant connector needs a catalog-domain migration and a data-class decision; every contractual and legal conclusion (data-sharing agreements, FERPA school-official designations, vendor terms) stays with qualified counsel.
