## D-1188 · Documentation is governed by a card, a gate and a change obligation, and a reference page must be held by a test

**Decided 4 Oct 2026** ([`../documentation/README.md`](../documentation/README.md)).
About three hundred documents existed and nothing said which a reader should open,
which could be trusted, or that a change owed its page. A parallel pass over the
repository added the layer for the people who use the thing — references, guides,
help, support, developer and trust pages, four runnable examples, release tooling —
and this records the rules that hold it.

- **A governed page opens with a card:** type, audience, owning seat, how it is
  held (`generated`, `held`, `reviewed`), the date a person last read it, and the
  test that holds it. The owner is a council seat, never a person. A `reference`
  may not be `reviewed` only. A test that claims to hold a page must name it or its
  folder.
- **The gate reads no clock.** Dead links, unreachable pages, filler words and
  unqualified compliance claims fail the suite; staleness is a report
  (`npm run docs:stale`), because a test that goes red when the calendar moves
  guards nothing.
- **A change owes its page.** `npm run docs:impact`, run by `.github/workflows/docs.yml`
  on every pull request, fails a change under the gateway, an edge function, a
  screen, a script or an example that touches no page that describes it, unless the
  description says `Docs: none because <reason>`. It is **blocking from the first day**. Making it advisory is a one-line
  change to the workflow if it proves too noisy for the pull requests already open. Facts that can be diffed (routes, codes, events,
  functions, variables) are held by their reference page's own test instead.
- **Nothing existing is moved** (D-002). The front door is `docs/README.md`; the
  complete list is the generated `docs/documentation/INDEX.md`.
- **Change-communication lead times are proposals.** No contract or policy in the
  repository sets a notice period, and `docs/releases/CHANGE-COMMUNICATION.md` says so.

**Not done.** No page has been read by a person from its audience; the first pilot
cohort is where that happens. `docs:stale` is not scheduled. `docs:impact` is not yet
a required status check on the ruleset. The pages record 30-odd places where the code
and an older document disagree (for example `Console` is gated to Semester operators
while the truth table calls it the tenant admin console, and `validateEvent` does not
check retention against the catalog); the older documents are not edited here. A
`ScimError` parameter property in `app/server/institution/scim.ts` stops the example
tests importing it statically; it is a one-line change outside this pull request.
