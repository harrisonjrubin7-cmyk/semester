## D-1486 · A red `main` is fixed at its cause, in one pull request, before anything else lands on it

**Decided 12 Oct 2026.** `build` had been red on `main`'s last six pushes, and every open pull request inherited the red, which made "CI is green" mean nothing for any of them.

- **What was decided.** Four fixes in one change: two tests that `main` broke on itself, and the CI step whose failure was only a shadow of theirs. The two test files that call `vi.mock` are listed in `MOCKS_MODULES`; the revoke test presses the confirmation the unified `DelegationRow` added; the PostgreSQL install step runs under `if: always()` like the policy step it serves; and the Export and Recovery route budgets are raised to what they measure.
- **Why the third is in here.** The policy step reported "no PostgreSQL 17" on every red build, and that reads as a runner fault. It was not: the install step was skipped after the failed test step, and the policy step, which does run on failure, found nothing installed. A gate that reports the wrong reason for being red is the shape this repository keeps recording; the fix is to make its dependency run on the same terms it does.
- **Why the fourth is in here.** Once the tests passed, the budget step ran for the first time since 11 October and found Export at 76.6 KB against 69.0 KB and Recovery at 74.5 KB against 62.0 KB. The growth is 178da3846, which made the workspace backup cover the Toolkit, whose schema brings its policy, research and template readers along; both screens import the backup. That growth is deliberate and the budgets file's own rule is to raise the number in the same pull request, which that commit could not do because the gate never ran on it. The numbers are what `budgets --print` suggests from the measurement, not a round figure.
- **Why not four pull requests.** Each fix alone leaves `build` red, so none could be shown green on its own, and the CI change is only legible next to the test fixes that exposed it.
- **Held by.** The full suite at 24,197 pass and 0 fail, where `main` had 2 fail. The reverts are `main`'s own runs 5432 through 5506, which print the two assertions this change answers.
- **Not done.** Why two test files that call `vi.mock` were merged without being listed is a review question for those merges, not this one. The policy test exists to catch it, and did.
