## D-1271 · The design-sync audit extends the existing token pipeline, holds drift on shrink-only ledgers, and does not touch Figma

**Decided 5 Oct 2026.**
An outside audit prompt assumed Semester had no design-system enforcement and no Figma plan. It has both: `lint` and `scripts/styles.mjs` hold the type scale, `styles/hex.test.ts` holds hex in `.tsx`, `lib/tokenexport.test.ts` holds `design-tokens/semester.tokens.json` to the code, and `docs/design/DESIGN-SYSTEM-PRODUCT-SPEC.md` §7.2 plans Figma parity. What nothing read was a colour literal in CSS or an inline style, a `var(--x)` that names nothing, and the Figma mapping itself.

- **What was decided.** `scripts/design-system-audit.mjs` fails on a colour literal above a file's ledger count, a `var(--x)` with no fallback and no definition above its name's ledger count, a ledger entry above what the tree holds (the ledgers only shrink, the idiom of `hex.test.ts`), a missing or wrong-schema token export, and a `docs/FIGMA-MAPPING.md` row whose path is not in the export, whose CSS name is not the path's, or whose Figma name is repeated. A semantic token with no row is reported, not failed, as spec §7.2 step 4 says. `design-system-report.mjs` prints the same figures and never fails unless `--strict`.
- **Why it reads the committed export.** Plain `node` cannot import `lib/look.ts` (its imports have no extension), which is why `tokens:export` runs under vitest. The audit reads the committed JSON and `tokenexport.test.ts` keeps that file equal to the code.
- **Measured.** 206 colour literals in 28 files and 24 undefined `var()` uses across 11 names (`--app-ink` ×9, `--app-border` ×3, `--app-paper` ×2, `--card` ×2, `--line` ×2, and six used once). A declaration such as `border: 1px solid var(--app-border)` is invalid at computed-value time and draws no border.
- **Figma.** `.mcp.json` declares the remote server over http with no credential. `docs/FIGMA-MAPPING.md` maps 119 semantic tokens, 43 primitives and 8 collections; every row is `Planned`, because no Figma file exists. Nothing in the repository writes to Figma.
- **Held by.** `src/styles/designsync.test.ts`: fixture trees built to break each rule and one built not to; the real tree fails with the ledger removed; a real mapping row pointed at a missing token fails. Adding a literal and an undefined variable to `features.css` turned the audit red and restoring it turned it green.

**Not decided here.** The 11 undefined variables are not fixed: each fix makes a declaration start to apply, which changes a screen, and that is for whoever owns the screen. Code Connect for components needs the Figma file. No CI job runs the report yet. Spec §7.2's first sentence (no token export exists) is out of date and is left for its owner. Named colours and hex in plain `.ts` files are not read.
