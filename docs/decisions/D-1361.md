## D-1361 · The access saga's store is written as inert, service-only tables and functions; applying them is the owner's

**Decided 6 Oct 2026**, on the owner's instruction to continue with C-6. Follows [D-1338](D-1338.md) and [D-1356](D-1356.md); the payment-rail pattern it copies is [D-1324](D-1324.md).

- **What was decided.** `20261006180000_access_saga_store.sql` adds `access_sagas`, `access_saga_events` and `access_saga_signals` with `claim`, `save`, `flag_recovery`, `release` and `wake`, the `Store` the saga runner was written against. Nothing calls them: no adapter, route, worker or job.
- **Why a migration, and why not applied here.** Tables are the only place a lease, a compare-and-swap and an atomic saga-plus-event write can live. Merging the pull request applies the migration to the connected project, so the pull request stays a draft until the owner says to apply it.
- **Where the guarantees are held.** In the database, not in an adapter that could forget: `save` checks the lease and the revision and writes the saga and its event in one transaction, raising `SC409` and writing nothing on a stale lease or a moved revision; a trigger holds every update to the saga's edges, one revision at a time, with identity fixed, a generation that moves only when a new evaluation starts, and no way out of a finished state; `wake` is applied once per event id.
- **A second copy of the edge list.** The SQL repeats `ACCESS_SAGA`'s edges. `access-saga-store.test.ts` compares states, edges and actions, so neither can change alone.
- **Retention.** No clock: nothing deletes these rows, and the period is not set. `RETENTION.md` says so for each table.
- **Held by.** 136 SQL checks (migrations applied twice) and seven deliberate removals, each caught. One survivor, signal dedupe, exposed a test that replayed a signal that did not apply anyway; it now replays one after the saga is waiting again. Run on Postgres 16; CI runs 17.
- **Not done.** The TypeScript adapter over these functions, the revocation barrier at a real enforcement point, and the crash rehearsals through the adapter.
