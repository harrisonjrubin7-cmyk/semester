## D-1260 · An AI request is refused before it is sent if it carries a field above the T2 data-class ceiling

**Decided 4 Oct 2026** (found in [`../privacy-operations/08-FINDINGS-AND-RECONCILIATION.md`](../privacy-operations/08-FINDINGS-AND-RECONCILIATION.md) C7).
The shared-key function and the institution gateway had an activation gate, a kill switch, a monthly cap and tenant policy, and none of them looked at what a request carried. `ai_policy` has no class field and `approved_source` has no class column; the only place a tenant expresses a class ceiling, `data_classification_rules`, is read by nothing on an AI path.

- **What was decided.** `packages/institution/src/ai-data-class.ts` is a pure check: a ceiling of T2 (the stricter of the platform floor, which routes T3 to `approved_ai`, and the toolkit gate, which does not), a field with no declared class counts as T3, and a verdict names fields, never values. `aiclass.test.ts` recomputes the ceiling from both and holds the vocabulary to `classification.ts`.
- **Shared key.** `clamp.ts` refuses (422 `data_class_refused`) a declared `data_class` above T2 or not one of the seven, and a `tool_use` / `tool_result` that names a T3 tool (`read_grades`, `read_attendance`) or one nobody classified. Those tools are no longer offered. `aitools.ts` is a copy of the registry's `data` column, held equal by `claudeclass.test.ts`. The function logs field names and the highest class, before the spend is reserved and the call counted.
- **Gateway.** Every field of `ProviderGenerationRequest` and `ApprovedIntelligenceSource` has a declared class (`Record<keyof ...>`, so a new field does not compile). `respond()` checks the request it built before reserving budget; a field with no class is refused 403 `data-class-refused` and audited as `data-class-refused:T3`, no content.
- **What it costs.** The shared-key assistant no longer gets grade or attendance lookups. A test fixture tool name `lookup` became `find_deadlines`, because an unclassified tool is now dropped.
- **Held by.** Tests watched red on the old code (3 behavioural failures with the controls green) and 14 red with the fix reverted; controls show an allowed-class request still goes through on both paths.

**Not decided here.** Free text is not read: prose is declared T2, as the product says it is, so a student who pastes a record into a question is not caught. Sources are declared T1 by construction, not by a column. A tenant ceiling lower than T2 (`data_classification_rules`) is not read; `flags.ts` `ctx.classification` still has no production caller. Whether T2 is acceptable for any provider, and what any provider's terms allow, is counsel's (P-12).
