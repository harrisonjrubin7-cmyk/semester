# Pilot to Production Activation Roadmap

Concept → repository verified → controlled preview → institution sandbox → UAT → limited pilot → measured outcome review → production approval → monitored expansion.

Required production evidence: owner and support; security/privacy/accessibility approvals; configured identity/integrations; data map and retention; negative and recovery tests; user acceptance; incident communications; SLOs; rollback; legal/commercial authority; and no expired evidence.
