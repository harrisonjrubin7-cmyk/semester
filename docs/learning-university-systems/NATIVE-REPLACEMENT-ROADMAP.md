# Native Replacement Roadmap

Replace domains independently. Start with personal learning work and preparation, then low-risk source-aware institutional workflows, then faculty/course operations, then selected authoritative records. A domain moves from integrated to native only after parity, migration tooling, reconciliation, audit, accessibility, support, peak-load proof, rollback, governance approval, and a successful parallel run.

No target date is a promise; evidence opens the gate.

---

Evidence baseline: `origin/main` at `8ccf55af`, assessed 2026-10-03. “Implemented” means repository evidence, not institutional approval or observed production operation.
