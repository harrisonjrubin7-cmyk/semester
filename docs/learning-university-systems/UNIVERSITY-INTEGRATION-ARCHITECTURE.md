# University Integration Architecture

Use a tenant-aware gateway with provider adapters, minimum scopes, field allowlists, signed inbound events, idempotent outbound commands, durable outbox, replay protection, quarantine, reconciliation, audit correlation, rate limits, circuit breakers, and per-tenant kill switches.

Separate source snapshots from derived student plans. UI reads normalized canonical objects plus lineage. High-risk writes require policy evaluation, explicit user/operator confirmation, provider receipt, and reconciliation.
