# 12-Month Academic Platform Roadmap

Months 0–3: refresh registers, close verification gaps, instrument core journey, complete pilot configuration kit, run independent accessibility/security reviews, and establish staffed support.

Months 3–6: one controlled institution pilot with read-only identity/course/calendar integration, registration-readiness and advising handoffs; collect baseline and burden.

Months 6–9: add faculty publication and submission pilot only if first pilot gates pass; rehearse migration and recovery.

Months 9–12: expand validated workflows and decide—using signed evidence—whether any gradebook/LMS domain enters parallel authoritative operation.

Evidence baseline: `origin/main` at `8ccf55af`, assessed 2026-10-03. “Implemented” means repository evidence, not institutional approval or observed production operation.
