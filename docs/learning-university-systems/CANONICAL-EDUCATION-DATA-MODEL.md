# Canonical Education Data Model

Domains: identity/tenant; academic calendar; catalog/program/requirement; course/section/enrollment/role; content/module/outcome; assignment/submission/assessment/rubric/grade; plan/registration intent; support/referral; service directory; credential/evidence; consent/policy; integration job/receipt; audit/evidence.

Canonical objects preserve provider IDs, version, authority, effective time, observed time, lineage, purpose, permissions, retention, and quality state. Provider-specific fields stay in adapters, not the core UI model.
