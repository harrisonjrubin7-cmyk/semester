# AI Academic Integrity Specification

Semester uses scaffolding, not substitution. Each course/assignment exposes allowed assistance; generated help stays within that ceiling. Draft help requires disclosure where policy requires it. Citations are suggestions until verified. The system does not infer misconduct or plagiarism from probabilistic output.

Required controls: source anchors; authorship checkpoints; change history; student confirmation; course-policy version; prohibited-mode refusal; instructor-readable policy, not private thought logs; appeal/correction route; and no automated punitive action.
