# Degree Planning and Audit Specification

Semester supports exploratory pathways and scenarios. Requirements are versioned by catalog year and authority. Each match shows the rule, source, confidence, exceptions, and unresolved items. Student changes never alter official curriculum data.

The UI calls results “plan” or “estimate” until registrar-certified. Official audit requires approved rules, transfer-credit decisions, substitutions, exceptions, residency/GPA logic, reconciliation, and registrar sign-off.
