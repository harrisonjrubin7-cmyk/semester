# Core Learning Journeys

## Primary loop

Identity → verified academic context → course home → next action → work plan → source-grounded study → feedback/reflection → recovery or support → progress evidence.

## Journey acceptance

1. The source, status, timestamp, authority, and next verification step remain visible.
2. A missed plan offers re-planning, never shame or a punitive streak.
3. AI outputs identify their selected sources and remain editable/rejectable.
4. No task is marked submitted or graded without authoritative evidence.
5. Keyboard, screen reader, zoom/reflow, reduced motion, and mobile paths are tested.

## Highest-friction journeys

Exam preparation, research-paper drafting, registration preparation, accommodation-aware work, and recovery after missed deadlines. These should drive pilot metrics rather than feature-count adoption.
