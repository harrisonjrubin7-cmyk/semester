# Integration Security and Privacy Standard

Require least privilege, tenant binding, secure secrets, rotation, sender verification, replay protection, allowlisted destinations, SSRF defenses, schema validation, malware/content controls, encryption, audit, retention, data-subject handling, incident routing, vendor review, and tested revoke/offboarding.

No connector is “production ready” from code alone. Activation requires configured credentials, threat review, privacy approval, successful negative tests, UAT, monitoring, owner, support, and expiry/review date.
