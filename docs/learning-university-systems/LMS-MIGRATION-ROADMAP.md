# LMS Migration Roadmap

1. Inventory and classify courses, content rights, tools, assessments, grades, outcomes, accommodations, and retention.
2. Dry-run import into quarantine; validate identity, links, files, accessibility, QTI, dates, and mappings.
3. Faculty review and repair; obtain sign-off.
4. Parallel-read period; no write authority.
5. Limited cohort with rollback and reconciliation.
6. Controlled cutover outside academic peaks.
7. Archive/export source system only after record and legal approval.

Exit requires reconciliation thresholds, support staffing, incident plan, restore evidence, user acceptance, and signed owner approval.
