# Institutional Admin Console Specification

The console manages tenant identity, roles, source connections, scopes, field mappings, feature modes, AI policy, retention, evidence, approvals, integration health, incidents, exports, offboarding, and audit search.

High-risk changes require preview, reason, separation of duties where configured, step-up authentication, immutable audit correlation, rollback, and notification. The console must distinguish configuration from actual provider connectivity and show evidence expiry.

Evidence baseline: `origin/main` at `8ccf55af`, assessed 2026-10-03. “Implemented” means repository evidence, not institutional approval or observed production operation.
