# Institutional Rollout and Migration Playbook

Discover → data map → authority map → security/privacy/accessibility review → configuration → migration dry run → reconciliation → role training → UAT → launch decision → controlled cohort → hypercare → outcomes review → expand, hold, rollback, or offboard.

Each phase has named owners, evidence, expiry, entry/exit criteria, risks, communications, and rollback. No academic-peak cutover without executive exception and tested recovery.
