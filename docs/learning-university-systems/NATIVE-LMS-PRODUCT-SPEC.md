# Native LMS Product Specification

The native LMS is a future institution-activated domain, not a default claim. Minimum release includes course templates, versioned modules/outcomes, accessible authoring, assignments, submissions with receipts, discussions/moderation, announcements, calendar, rubrics, assessment delivery, gradebook, release controls, roster/roles, accommodations, analytics, import/export, audit, retention, support, and rollback.

Every record carries tenant, term, course, owner, source, version, status, timestamps, permissions, retention class, and audit correlation. Faculty preview and publication are separate permissions. Grade release and external writes require explicit confirmation.

Evidence baseline: `origin/main` at `8ccf55af`, assessed 2026-10-03. “Implemented” means repository evidence, not institutional approval or observed production operation.
