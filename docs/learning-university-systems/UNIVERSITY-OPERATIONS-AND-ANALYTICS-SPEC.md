# University Operations and Analytics Specification

Dashboards report adoption, journey completion, handoff success, source freshness, integration health, accessibility issues, support burden, incidents, data quality, and outcomes with privacy floors. They do not rank students or expose private learning behavior without a governed purpose.

Metrics have owner, definition, numerator/denominator, cohort, exclusions, freshness, privacy rule, target, and decision use. Empty or too-small cohorts return “insufficient data,” never zero.
