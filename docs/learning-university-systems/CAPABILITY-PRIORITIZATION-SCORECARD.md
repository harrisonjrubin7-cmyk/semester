# Capability Prioritization Scorecard

Score 1–5 for student outcome, learning value, institutional value, differentiation, pilot evidence, time to value, reversibility, and debt reduction. Reverse-score effort, operating cost, security/privacy, accessibility, legal, integration, data-quality, support burden, evidence burden, and harm if wrong.

Decision rule: any capability with unresolved tenant isolation, misleading authority, accessibility blocker, high-impact AI, or absent accountable owner is held regardless of total. Prefer the course→action→study→feedback→support loop over new standalone modules.
