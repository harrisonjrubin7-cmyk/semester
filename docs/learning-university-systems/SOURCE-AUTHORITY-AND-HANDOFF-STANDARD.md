# Source Authority and Handoff Standard

Every consequential fact displays: origin, authority class (official/synced/imported/user-entered/estimated/AI-generated/incomplete), last update, freshness, scope, permitted action, verification step, and issue-report path.

Authority order is configured per field, never inferred from visual prominence. Conflicts remain visible until reconciled. Handovers show sender, receiver, selected data, purpose, expected result, status, receipt, retry, and support path.
