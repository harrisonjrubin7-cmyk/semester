# Templates

> **Type:** reference · **Audience:** contributors · **Owner:** `engineering` · **Truth:** held · **Reviewed:** 2026-10-04 · **Held by:** `app/src/lib/docs/docsystem.test.ts`

One skeleton per kind of page. Copy the file, change the card and the
headings' content, delete what does not apply, and keep the order: the order is
the reason the template exists.

| Write a… | Copy | Use it when |
| --- | --- | --- |
| Tutorial | [`tutorial.md`](tutorial.md) | A newcomer should succeed once by following along |
| How-to | [`how-to.md`](how-to.md) | A competent reader has a goal and needs the steps |
| Reference | [`reference.md`](reference.md) | A fact must be exactly right and findable |
| Explanation | [`explanation.md`](explanation.md) | The reader needs to understand why |
| Runbook | [`runbook.md`](runbook.md) | Someone is under pressure and needs the next step |
| Help article | [`help-article.md`](help-article.md) | A person using the product has a task |
| Support article | [`support-article.md`](support-article.md) | A person has a problem and says it in their words |
| Release note | [`release-note.md`](release-note.md) | A dated cut is communicated to a cohort or an institution |
| Deprecation notice | [`deprecation-notice.md`](deprecation-notice.md) | Something that works today will stop |
| Institution change notice | [`institution-change-notice.md`](institution-change-notice.md) | An administrator must act, or be told before their users are |

Templates carry a valid card, so they are held to the same gate as every other
page. Their placeholders are written in angle brackets; a page that still has
one is not finished.
