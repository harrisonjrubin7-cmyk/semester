# Support handoff — readiness pilot

| Student says | What it means | Do | Don't |
|---|---|---|---|
| "It says blocked" | An active hold or failed check | Name the office on the case; help them contact it | Clear or explain away the hold |
| "It says stale" | Vanderbilt's system hasn't updated recently | Tell them it's not final; offer refresh; escalate if a window opens within 48 h | Say it's probably fine |
| "Am I registered?" | Readiness ≠ enrollment | Point to the SIS and their time ticket | Say yes |
| "This is wrong" | Possible source or mapping error | Open a discrepancy case with the case id and correlation id | Edit any record |
| "I can see someone else's info" | Possible access failure | **SEV-1**: capture the screen route and time, escalate to security immediately | Ask them to send screenshots of the data |

Escalation: pilot operations lead → registrar counterpart (for record questions) / security owner (for access).
