# Registrar readiness pilot — 15 minutes

## You will be able to
1. Read source and freshness labels.
2. Tell a readiness state from enrollment.
3. Route a blocker without editing an institutional record.
4. Request an override without approving it yourself.
5. Escalate a stale-source or reconciliation issue.

## Practice scenario
A student has a current time ticket but stale prerequisite data.
**Expected:** acknowledge the stale source · request a refresh or route for review · don't mark the student ready or enrolled · leave an auditable note.

## Never
Mark a student enrolled · replace a SIS value by hand · open records outside your scope.

## Advisors (5-minute version)
You see only students assigned to you, read-only. You can refer; you can't route, override or change state.
