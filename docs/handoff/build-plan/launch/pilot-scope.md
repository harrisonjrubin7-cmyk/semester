# Pilot scope — registration_readiness_v1 at Vanderbilt

**Status:** Signed paid pilot with Vanderbilt — launch Spring 2027, pending institutional activation.

## In
- Students in the named pilot cohort see whether Semester has what it needs to help them get ready to register for Spring 2027: holds, time ticket, prerequisite evidence.
- Each check shows its source and how current it is.
- Students can refresh a stale check, or ask the right office for help.
- Registrar staff see a scoped queue of cases that need action, can route them to an office, and can request (not approve) an override.
- Operations see source health and incidents, without student details.

## Out
Enrollment submission · grade changes · payments · family data sharing · AI use of student records · any write to the SIS.

## What stays official
Vanderbilt's student information system. A readiness result is never enrollment.
