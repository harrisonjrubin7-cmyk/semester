# Coursework dashboard checklist

Fictional sample / local prototype. Not an official gradebook.

## Syllabus audit
- [ ] Confirm grading model: total points, equal assignments, or weighted categories.
- [ ] Enter the complete assignment inventory before relying on final targets.
- [ ] Verify category weights total 100%, or assignment points match course total.
- [ ] Record target percentage and letter-grade threshold; do not assume rounding.
- [ ] Verify deadline time and institutional timezone.
- [ ] Record rubric criteria, required files, milestones, and mandatory-pass rules.
- [ ] Record dropped-score, extra-credit, resubmission, and excused-work policies separately.

## Late penalties
- [ ] Identify basis: earned score percentage, possible points percentage, or percentage points.
- [ ] Record rate, late-day rounding, grace period, cap, exceptions, and hard cutoff.
- [ ] Enter chargeable late days manually after applying the syllabus grace rule.
- [ ] Confirm whether entered scores already include penalties.
- [ ] Test floors at zero and cap behavior.

## Browser tests
- [ ] Writing sample: adjusted essay 81/100; remaining target 89%.
- [ ] Data Science sample: adjusted notebook 40/50; current grade 80%; remaining target 90%.
- [ ] Product Studio sample: adjusted research 85/100; remaining target 85%.
- [ ] Blank scores remain unknown; graded zero remains zero.
- [ ] Mark pending work missing; toggle missing-as-zero and verify changed denominator/target.
- [ ] Already-adjusted score bypasses another late deduction.
- [ ] Invalid score, negative late days, and noninteger late days block calculation.
- [ ] Required target above 100% is flagged as infeasible under the model.
- [ ] Export/import a backup and verify data; reload to check local persistence.
- [ ] Test keyboard focus, controls, and narrow-screen overflow.

## Final delivery
- [ ] Complete content, citations, academic-integrity, accessibility, and format checks.
- [ ] Open final files and verify versions.
- [ ] Submit in the authoritative course system.
- [ ] Verify submitted version and save receipt.

## Limitations
Complete inventory required. Future target scores are post-penalty goals, not automatically calculated raw scores. Automatic drop selection, grace periods, deadline timestamps, extra credit, mandatory-pass rules, and late cutoffs are not implemented. Checklist selections in the HTML are session-only. No live LMS integration.
