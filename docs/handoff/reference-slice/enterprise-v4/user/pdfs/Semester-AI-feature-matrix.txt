Built the interactive dashboard, along with standalone CSV and JSON feature-matrix exports. It
includes dark mode, visual comparison charts, a study-schedule generator, and a quiz tracker
that compares your recorded RemNote and Gemini Notebook results.
Component Function
Feature matrix Compare 12 entries across reading, notes, tutoring, and quiz generation; filter by module or search.
Evidence chart Compare advertised/documented feature coverage—not product quality.
Quiz-performance chart Compare weighted accuracy by app and module using results you enter.
Schedule generator Choose a start date, 1–60 days, and daily study time; alternate apps within each module.
Weakness prioritization Order modules by lowest recorded accuracy, with rotation as the fallback when data is missing.
Quiz tracker Record app, module, topic, correct answers, total questions, duration, and date.
Completion tracking Mark scheduled sessions complete.
Export controls Export the matrix, schedule, and attempts as CSV, or the full dashboard data as JSON.
Dark mode Switch themes; the dashboard remembers the preference when browser storage is available.
The feature matrix retains the evidence distinction: Semester AIʼs reading, scanning, and
tutoring functions are advertised, while its quiz generation remains unverified. Gemini
Notebook and RemNote document quiz-generation workflows.

It starts empty—there are no invented scores or benchmark results.
This is a local dashboard prototype, not a live integration. It does not scan documents, generate
AI questions, retrieve quiz results from either app, or create calendar events.
The schedule is a configurable planning heuristic—not a validated spaced-repetition algorithm.
Results from different topics, question difficulty, or quiz lengths should not be treated as a
controlled comparison of the apps.
The attached CSV and JSON contain the feature matrix. Once you add attempts and generate a
schedule, use the dashboardʼs export controls to capture those additional records. Browser-
local persistence depends on storage availability; clearing browser data may remove saved
progress.
