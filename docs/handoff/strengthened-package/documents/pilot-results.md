# End-of-term pilot results template
Control: owner/version/cohort/term/accepted target and publication status.
Measures versus baseline: unavailable; require frozen method, denominators, source coverage and uncertainty.
Adoption: invited/activated/firstvalue/active cohorts, retention of observations and lag policy.
Support: case mix/severity, response/resolution distributions, paused reasons and staffing costs.
Trust: security/privacy/accessibility review, incidents, rights requests and unresolved findings.
Recommendation: renew/narrow/remediate/stop against agreed criteria.
Decision: named institutional authority, exact conditions, responsible owners and reference permission.
