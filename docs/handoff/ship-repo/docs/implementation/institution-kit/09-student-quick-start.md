# Student quick start

1. Open Semester and choose **Registration readiness**.
2. Press **Check my readiness**. You'll see what your school's records show, with the source and time on each item.
3. If something's blocking you, press **Ask [office] to review**. You'll get a receipt.
4. **This isn't registration.** You still register in YES.
5. If it says *Can't confirm right now*, your school's system hasn't updated — nothing is wrong with your account. Try again later or contact the Registrar.
