# Scope and non-goals

**In scope:** readiness check for the named cohort; holds, time ticket, active term, prerequisites (read-only from the SIS); referral to the owning office; receipts; registrar queue.

**Not in scope:** registering students, changing any SIS record, overriding holds or prerequisites, degree audit, grades, billing, AI-generated decisions.

**Prohibited claim:** "Readiness confirms enrollment."
