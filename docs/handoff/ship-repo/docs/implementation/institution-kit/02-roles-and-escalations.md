# Roles and escalations

Uses `docs/delivery/decision-rights.yaml` in the build plan. Fill names there; this page lists who to call.

| Situation | First contact | Escalates to |
|---|---|---|
| Student confused by a result | Semester support | Registrar business owner |
| Wrong result suspected | Registrar business owner | Semester product owner |
| Source stale or down | Institution technical owner | Semester on-call |
| Possible data exposure | Semester incident contact | Institution security contact |
