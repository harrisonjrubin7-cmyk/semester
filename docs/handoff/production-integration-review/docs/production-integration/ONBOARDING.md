# User onboarding and workspace setup

## Individual student — existing documented path
1. Open Semester; explain device-only work versus account sync.
2. Complete study preferences without requiring optional device permissions.
3. Create/sign into an account, or continue locally where supported.
4. If confirmation is required, explain pending status and offer resend/recovery; do not claim signed-in sync prematurely.
5. Add a syllabus or supported source. Explain any AI processing before sending content.
6. Review extracted course information, quoted sources and deadlines; confirm before saving.
7. Create a personal action and see it in Today/calendar.
8. Explain private notes, submissions, official data and source labels.
9. Offer sharing, notifications and connectors separately; declining must retain usable alternatives.
10. Verify local persistence or actual account sync as appropriate.

## Institution setup — proposed authorized flow
Accountable sponsor/IT/data steward → tenant/environment decision → agreements and privacy map → identity/claim mapping → explicit grants and scopes → source mappings/freshness → test identities/fixtures → reconciliation → role training → approved activation. Claimed email domain does not prove enrollment. Institutional workspaces must not be provisioned from self-selected role labels.

## Faculty and teaching team
Accept approved membership → select course/section → inspect teaching delegation → import or author material → review accessibility and AI rules → student preview → publish under policy. Explain which grades are working versus official. Reject out-of-scope courses/sections.

## Advisor/registrar/staff
Assigned scope → role training → source and authority inspection → read-only practice → approved task → consequence preview → receipt/reconciliation. No universal staff browse privilege. Route exceptions to the accountable office.

## Board/investor
Approved invitation → required identity controls → explicit audience/access scope → read-only reporting → definitions/source/limitations → selected documents → expiry/revocation. Board permission does not confer institution access.

## Completion evidence
Correct context; authorized home; unauthorized routes denied; first useful action completed; source understood; preferences reversible; sync status truthful; support reachable. Record acceptance without unnecessary personal-data collection. Offboarding must revoke applicable access while respecting official retention and personal portability.
