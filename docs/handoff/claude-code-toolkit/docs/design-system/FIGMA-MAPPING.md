# Figma ↔ code mapping

> **Status: template.** No Figma file has been inspected yet, so every *Figma* name below is a **proposed** name, not a fetched one. The *Exported path* column is real: each path was checked against `app/design-tokens/semester.tokens.json` at main@5eba494. When a Figma file is connected, replace proposed names with fetched ones and set **Status** per row.

## Ownership

| Concern | Owner |
| --- | --- |
| Behaviour, accessibility, responsive layout, public component APIs, token values | Code |
| Approved visual intent, exploration | Figma |
| Token pipeline | `lib/look.ts` (values) → `styles/tokens.css` (semantic names) → `lib/tokenexport.ts` → `design-tokens/semester.tokens.json` (generated) |

## Mapping rules

1. No Figma variable becomes a production token without a code PR to `look.ts` / `tokens.css` and a regenerated export.
2. No Figma component becomes a React component automatically — map it to an existing pattern first (`build-semester-ui`, `create-semester-component`).
3. Missing states in Figma never remove code requirements (loading, empty, error, disabled, permission, keyboard, focus, responsive).
4. Anything unresolved goes in **Unresolved** below with an owner.
5. Status vocabulary: `Match` · `Partial` · `Missing in Figma` · `Missing in code` · `Obsolete` · `Proposed (unverified)`.

Rows are machine-read: the first column that starts with `primitive.` or `semantic.` is checked. Keep one variable per row.
