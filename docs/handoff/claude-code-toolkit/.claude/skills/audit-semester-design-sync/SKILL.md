# Audit Semester Design Sync

## Semester-specific source of truth

Semester is an existing Vite + React application under `app/`. Do not impose a monorepo, Tailwind, Storybook or a package-based design-system architecture.

Source-of-truth order:

1. `app/src/lib/look.ts` — `tokensFor`: the only place a colour, radius or per-setting value is decided (13 grounds × 11 accents, density, corners, text size, text spacing).
2. `app/src/styles/tokens.css` — the semantic layer (surface, text, border, action, status, chart, focus, target, motion, layer, elevation, shape, layout, component). Writes no colour; `styles/tokens.test.ts` holds that.
3. `app/src/lib/tokenexport.ts` — `buildTokenExport(tokensCss, appCss)`: collections `ground · accent · density · textSpacing · textSize · corners · stylesheet · constant`; `primitive.*` variables with per-mode values under `$extensions.semester.modes`; `semantic.*` as `{primitive.x}` / `{semantic.x}` references.
4. `app/design-tokens/semester.tokens.json` — generated by `npm run tokens:export` (from `app/`). Never edit by hand; `src/lib/tokenexport.test.ts` fails on drift.
5. Implementation — `app/src/styles/`, `app/src/components/` (incl. `components/unity/` shared primitives), `app/src/screens/`, `app/src/screens.tsx`.
6. Contract tests — `app/src/styles/*.test.ts` (breakpoints, deadcss, density, fields, glass, gutter, hex, inset, mapcredit, motion, print, reach, scale, stacking, sweepdensity, taps, textbuttons, textscale, tokens), `lib/contrast.test.ts`, `lib/tokenexport.test.ts`, `a11y/*.test.ts`, `rootunmount.test.ts`.
7. Figma — evidence of approved visual intent. Code owns behaviour, accessibility, responsiveness and tokens. Figma variables must map to exported paths in `docs/design-system/FIGMA-MAPPING.md`.

## First command

From `app/`: `npm run design-system:report` (writes `app/reports/design-system/report.md`). It prints the current audit (raw colours vs the `hex.test.ts` ledger, undefined custom properties, export ↔ tokens.css sync, Figma mapping resolution). Use its numbers as evidence; do not re-derive them by hand.

## Figma workflow (only if a URL/node is supplied)

1. Use the configured Figma MCP tools to read node hierarchy, variables and collections, component instances and properties, auto-layout, visible states and text.
2. Compare Figma variables to `semester.tokens.json` paths and `docs/design-system/FIGMA-MAPPING.md`; compare collections to the export's collections (`ground` 13 modes, `accent` 11, `density` 3, `corners` 4, `textSize` 4, `textSpacing` 3).
3. Compare Figma components to `components/unity/*` and `components/ui.tsx` primitives (ObjectCard, ContextBar, StatusChip, ProvenanceChips, ActionPreview, States, Visibility, Table, Combobox, DateField, OpenIn, NextSteps, ScreenGuide).
4. Never create raw CSS to reach pixel parity. Never treat an incomplete frame as permission to omit keyboard support, focus, empty/loading/error/offline/permission states, responsive behaviour, labels or semantic HTML.

## Audit checks

**Tokens:** raw hex/rgb/hsl/oklch outside `look.ts` and the `hex.test.ts` ledger · arbitrary shadows, radii, z-indexes (vs `--layer-*` and `stacking.test.ts`), durations/easing (vs `--motion-*` and `motion.test.ts`) · custom properties used but never defined · tokens.css names missing from the export · export paths not traceable to tokens.css or `tokensFor` · Figma variables without a mapping.

**Components and patterns:** feature-local copies of unity primitives · trust vocabulary typed as string literals instead of `statusOf` / `TRUST_TEXT` · AI output not labelled `ai_assisted` · consequential actions without `ActionPreview` + `Recovery` · clickable divs, unlabelled icon buttons, buttons-as-links · density/type/surface drift · card-in-card.

**Responsive:** the tiers in `breakpoints.test.ts` (rail 0 / 72 / 196–232 / 248 / 272) · `--page-pad` 18/20/30 · overflow, truncation, long copy, 400% reflow · table regions scroll, not the document · sticky/fixed stacking.

**Accessibility:** one `main` + one H1 · skip link · label/hint/error association · dialog/menu focus · `--focus-clear-*` scroll margins · 44px targets (`taps.test.ts`, 24px exceptions with keyboard parity) · contrast measured on every surface of a ground · never colour alone · reduced motion and `data-calm`.

## Severity

- **Blocker** — breaks critical usability, accessibility, token integrity or release.
- **Major** — repeatable drift or a broken component/pattern/responsive contract.
- **Minor** — localised inconsistency or documentation gap.

## No-edit mode

Do not modify source during an audit unless the user asks after reviewing the report. Read-only commands and the existing test/audit scripts are fine.

## Rules for recommendations

Preserve the token and export architecture · extend, never add a parallel source of truth · use current tests before new tooling · no Tailwind/Storybook/monorepo/package migration · no component for a one-off · never raw values to match Figma pixels · prefer semantic variables, existing classes and unity primitives.
