## Measures fixed before collection

Use two or three workflow measures plus support and accessibility measures. A measure needs a source, calculation and owner before the baseline is collected.

| Measure | Why it matters | Source and calculation | Baseline | Target or decision threshold | Owner |
| --- | --- | --- | --- | --- | --- |
| Weekly active share of invited cohort | Adoption, not academic performance |  |  |  |  |
| In-scope workflow completion | Whether the chosen workflow is usable |  |  |  |  |
| Support requests per 100 participants | Operational load |  |  |  |  |
| Reported accessibility barriers | Barriers requiring remediation | Support and accessibility reports; target is zero but reports are never suppressed |  |  |  |
| Sponsor-defined outcome | The institution’s own reason for the pilot |  |  |  |  |

## Collection rules

- Use aggregate reporting and do not report a group smaller than ten people.
- Do not infer academic risk, wellbeing, motivation or disability from product activity.
- Participation is optional and has no effect on grades or standing.
- Fix definitions before collection. Do not change a measure after seeing results without recording the change and reason.
- Record missing data and null results. Do not replace them with estimates unless the method explicitly allows and labels an estimate.
