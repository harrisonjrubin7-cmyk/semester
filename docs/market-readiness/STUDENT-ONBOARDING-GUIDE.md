# Student onboarding guide

The first session should explain what Semester is, what the pilot includes, who can see what, how data is used, where information comes from, how to get human help, and how to leave/export/delete where applicable. Ask only for the minimum context needed to create a coherent Today/This Week plan.

Students should be able to skip optional profiling, recover from incomplete data, distinguish examples from their own records, correct/reject AI output, manage notifications, and see clear integration/source/freshness state. Completion is the first win—not profile fullness.

See [STUDENT-ONBOARDING-SPEC.md](STUDENT-ONBOARDING-SPEC.md). Final copy requires counsel/privacy, accessibility, customer, and representative student review.
