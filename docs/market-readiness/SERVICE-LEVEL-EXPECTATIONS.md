# Service level expectations

No contractual SLA, uptime percentage, 24/7 response, RTO, RPO, or implementation duration is currently approved.

Before a pilot, publish supported hours, channels, severity definitions, target first-response/update intervals, escalation path, maintenance/change notice, provider dependencies, exclusions, data-rights handling, incident communication, and review cadence. Label these as operating targets unless counsel and accountable operators approve contractual commitments.

Measure actual response, resolution, availability, recovery, and support burden during design-partner work before offering stronger commitments. See [PILOT-SUPPORT-RUNBOOK.md](PILOT-SUPPORT-RUNBOOK.md) and [BUSINESS-CONTINUITY-AND-DISASTER-RECOVERY.md](BUSINESS-CONTINUITY-AND-DISASTER-RECOVERY.md).
