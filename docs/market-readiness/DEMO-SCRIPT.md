# Demo script

## Common opening

Start with the buyer’s stated problem and show the capability legend: **available in repository**, **available only after pilot configuration/acceptance**, and **planned/unavailable**. Use synthetic data unless an authorized environment and approved data are available.

## 10–15 minute executive demo

Problem → student first win → privacy-thresholded institutional first proof → implementation/support/limits → proposed pilot decision.

## 30 minute operational demo

Cohort setup → onboarding → Today/This Week/workload/checklist → support/recovery → aggregate review → weekly operating loop → offboarding.

## 45–60 minute technical/security walkthrough

Architecture/data flow → identity/roles/tenant/RLS → audit/monitoring → privacy/retention/export/deletion → integrations/degraded mode → incident/restore/rollback → evidence gaps and acceptance plan.

## Student demo

Minimum setup → coherent plan for today/week → source/freshness and incomplete-data recovery → help/privacy controls → export/delete path.

End every version with a concrete next step: qualified discovery, evidence exchange, pilot-scoping workshop, or no-fit decision. See [DEMO-PLAYBOOK.md](DEMO-PLAYBOOK.md).
