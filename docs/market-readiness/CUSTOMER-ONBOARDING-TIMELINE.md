# Customer onboarding timeline

| Window | Customer and Semester outcomes |
| --- | --- |
| days 0–5 | kickoff, owners, cohort/workflow, data map, trust and contract issue log |
| days 6–15 | agreement/data approval, sandbox tenant, roles/features, baseline design |
| days 16–30 | content/configuration, admin/support training, external reviews/remediation |
| days 31–45 | student/admin UAT, accessibility, adversarial, rights, incident/restore/rollback rehearsals |
| days 46–60 | launch council, baseline and support/hypercare readiness; signed GO or delay/stop; only after signed GO, release approved communications and invitations |
| weekly after launch | aggregate scorecard, guardrails, issues/changes and decisions |
| midpoint/final | outcome report and convert/expand/pause/stop decision |

No date overrides an unmet gate.
