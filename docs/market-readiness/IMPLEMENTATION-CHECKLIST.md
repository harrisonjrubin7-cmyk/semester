# Implementation checklist

- [ ] signed charter, agreement/DPA position, price/quote, scope, exclusions, cohort, milestone, and decision date
- [ ] named sponsor, champion, engineering, security, privacy, accessibility, support, finance, counsel, and backups
- [ ] approved data flow, purpose, minimum fields, retention, subprocessors, export/deletion, and offboarding
- [ ] approved tenant, roles, capability expiry/revocation, features, disabled features, providers, and kill switches
- [ ] security, privacy, accessibility, integration, legal, and procurement evidence accepted
- [ ] configuration and audit exports retained
- [ ] operator/student communications and training completed
- [ ] golden-path, mobile, keyboard, slow/failure, degraded, rollback, incident, restore, support, and deletion/export acceptance completed
- [ ] baseline, targets, event validation, privacy threshold, reporting cadence, midpoint/final criteria approved
- [ ] launch council signed GO with no open P0/P1
- [ ] weekly review, change control, closeout, conversion, and clean offboarding scheduled

Use [the pilot launch checklist](PILOT-LAUNCH-CHECKLIST.md) for evidence fields. An unchecked item remains a gate, not an implied pass.
