# First 10 institutions targeting plan

Select prospects only from real warm paths or explicit observed needs; do not fabricate relationships. Build a private list of 10 across: first-year/transfer success, advising/programs, registration/enrollment, honors/learning communities and regional/private institutions with shorter pilot paths.

Score 0–2 on urgent milestone, 50–200 cohort fit, champion access, economic buyer, procurement feasibility, manual/read-only fit, timing, evidence value, implementation capacity and reference potential. Start with the top three; maintain a clear disqualification reason and next action. Public materials may name an institution only with permission.
