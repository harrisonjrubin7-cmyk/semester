# Pilot agreement issue list

Parties/authority; scope/cohort/term; fees/taxes/payment; permitted use and exclusions; responsibilities/acceptance; data roles/FERPA-oriented school-official terms where applicable; security/privacy/accessibility; subprocessors/AI; confidentiality/IP/feedback; support/service targets; change control; warranties/disclaimers; liability/indemnity; insurance; incident notice; records/retention/export/deletion/legal hold; publicity/reference consent; termination/suspension; conversion credit; offboarding; governing law/disputes.

Open decisions must be resolved by counsel and the responsible control owner. Product copy and proposal must match the executed scope.
