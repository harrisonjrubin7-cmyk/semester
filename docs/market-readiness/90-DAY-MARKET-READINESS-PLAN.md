# 90-day market-readiness plan

This is a gated plan, not a forecast. External owners and evidence can extend dates.

| Week | Objective and measurable output | Accountable | Dependencies | Go/no-go / release criterion |

## Workstreams and definitions of done

- **Product/engineering:** exact golden paths pass functional, adversarial, accessibility, recovery and rollback acceptance in target environment.
- **Trust/legal:** customer-scoped data/AI/subprocessor/contract package approved; external findings closed or launch-blocking.
- **Delivery/support:** named rota, training, escalation, weekly review and offboarding rehearsed.
- **Commercial:** qualified pipeline, approved proposal/price logic, decision date, no unsupported commitments.
- **Evidence:** baselines, event validation, privacy thresholds and outcome report signed by the customer.

## First ten institution targeting filters

Build the list from institutions/programs where a warm path or explicit need exists. Score urgency, cohort fit, champion access, procurement path, data simplicity, timing, implementation capacity and reference potential. Do not publish names or claim relationships until the institution agrees.

## First 1,000 students

Reach 1,000 through several 50–200 student cohorts plus individual/manual-first adoption—not one ungoverned campus blast. Advance a channel only when activation, week-4 retention, support load, privacy requests and accessibility guardrails remain acceptable.
