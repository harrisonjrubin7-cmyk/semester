# Administrator onboarding guide

1. Complete role, privacy, security, accessibility, support, and incident training.
2. Review signed scope, prohibited uses, cohort, minimum data, permitted measures, and known limitations.
3. Verify tenant, roles, expiry/revocation, features, disabled features, privacy thresholds, and support contacts.
4. Practice student invitation, aggregate review, audit lookup, help escalation, read-only/degraded mode, rollback request, export/deletion, and offboarding using synthetic data.
5. Sign the operator acceptance record; no admin receives production access before approval.

Administrators may not use Semester for undisclosed surveillance, individual risk labeling, or high-impact automated decisions. See [PILOT-ADMIN-RUNBOOK.md](PILOT-ADMIN-RUNBOOK.md).
