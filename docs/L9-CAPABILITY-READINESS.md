## Gate meanings

| Level | Required proof |
| --- | --- |
| L0 | Vision |
| L1 | Designed capability in the canonical catalog |
| L2 | Implementation is partial or complete |
| L3 | Canonical repository verification |
| L4 | Complete definition-of-done evidence across product, authorization, accessibility, security, support, monitoring, rollback, lifecycle, and claims |
| L5 | A named tenant approved the capability |
| L6 | The same tenant completed a parallel run |
| L7 | The same tenant completed bounded live operation |
| L8 | The same tenant reached GA |
| L9 | Repeatable current evidence across at least two tenants and two operating cycles |
