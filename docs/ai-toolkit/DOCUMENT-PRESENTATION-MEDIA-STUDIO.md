# Document, presentation and media studio

These already exist in Semester; the toolkit routes to them.

| Brief capability | Where it lives |
| --- | --- |
| Essay, report, memo, lab report, proposal, policy brief templates | Write a document; toolkit templates for the stages |
| Revision history | Write (document versions) |
| Citation / reference organizer | Sources; Research Studio export |
| Grammar, structure, quotation checks | Check the writing |
| Rubric interpreter (self-check, never a grade) | Toolkit → Rubric self-check |
| Provenance panel | Toolkit assignment workspace (all student-authored) — see [ACADEMIC-WORK-PROVENANCE.md](ACADEMIC-WORK-PROVENANCE.md) |
| Slides, speaker notes | Make a deck |
| Diagrams and figures | Draw it |
| Captions and transcripts | Existing course-audio transcript pipeline |

## Media rules the toolkit adds nothing to break

- Student media is private by default; nothing in the toolkit publishes.
- No voice cloning of faculty or students (`NEVER` → `voice-cloning`).
- No copyrighted media without rights (catalog `copyright` boundary on art, music,
  theatre and film tools).

## Not built

Recorded rehearsal with timing, poster templates, portfolio with consent flow,
storyboard / call-sheet tools.
