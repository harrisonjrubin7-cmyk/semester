# Academic work provenance

## States (brief)

| State | In this slice |
| --- | --- |
| Student-authored | Every stage note, reflection, research field, dictionary entry, cleaning reason and interpretation. The toolkit writes none of them. |
| Source quotation / reference | Evidence entries, with the quotation checked against the pasted passage |
| AI-assisted / source-linked | Not produced by the toolkit. Study guides built in Study are labelled *AI-assisted draft* there, with matched quotations. |
| Student revision | Stage reopen; document versions in Write |
| Source-to-output lineage | Claim → evidence links; data export → cleaning log → raw data |

The assignment workspace's provenance panel says so plainly: *Everything in this
workspace is your own writing. The toolkit generated none of it.* That sentence is
true because nothing in `components/toolkit/` calls a model — a claim a reviewer
can check with a search for `ask(` in that folder.

## Export for submission

Student-controlled downloads: workspace notes (Markdown), references (RIS, BibTeX),
methods and results (text), cleaned data (CSV), AI-use declaration (text). Nothing is
sent to the LMS; the checklist ends with *You submit it yourself, through the
course's own system*.

## Not surveillance

Provenance is for the student to show their work, not for anyone to monitor it.
Nothing is logged remotely, and nothing reads declarations or provenance to score,
flag or profile.
