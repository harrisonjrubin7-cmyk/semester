# Privacy operations evidence

Dated records that a privacy procedure was actually run. A procedure counts as exercised only when it has a file here.

Never store personal data, matter details of a legal hold, or ID images here. Use request ids, counts and role titles.

| Folder or file pattern | What goes in it | Template |
| --- | --- | --- |
| `dsr-rehearsal-YYYY-MM-DD.md` | Quarterly rehearsal: access, erasure on a test account, guardian-originated, with a hold | `docs/legal-drafts/DSR-OPERATING-KIT-TEMPLATE.md` §10 |
| `dsr-log-YYYY-MM.md` | Monthly export of the request log, ids only | same, §9 |
| `breach-tabletop-YYYY-MM-DD.md` | Tabletop using the breach worksheet | `docs/legal-drafts/PRIVACY-BREACH-ASSESSMENT-WORKSHEET-TEMPLATE.md` |
| `breach-log.md` | One row per incident, including no-duty decisions | same |
| `reviews/YYYY-MM-DD-<feature>.md` | Completed privacy-by-design intake | `docs/legal-drafts/PRIVACY-REVIEW-INTAKE-TEMPLATE.md` |
| `vendors/<vendor>.md` | Vendor review record and monthly change notes | `docs/legal-drafts/VENDOR-PRIVACY-REVIEW-TEMPLATE.md` |
| `minors-<date>.md` | Age-gate and guardian procedure exercises | `docs/legal-drafts/MINORS-AND-GUARDIAN-OPERATIONS-DRAFT.md` |
