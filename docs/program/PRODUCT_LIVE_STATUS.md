## 2. What a person can do today

| Audience | Reality | Evidence |
| --- | --- | --- |
| A student on the hosted PWA, signed out | Use the app on-device: tasks, calendar, notes, docs/sheets/decks, files, study tools. Data lives in localStorage/IndexedDB. Works offline. | `app/src/lib/cloud.ts` header; `app/public/sw.js` |
| A student, signed in | Same, plus a field-wise merge of one JSON blob and per-course rows to Postgres; device/account lifecycle; export and erasure RPCs | `cloud.ts`, `export_my_data`, `erase_account`; `account-sync` required check |
| A student wanting AI | Claude through the shared-key function (plan clamp, per-user spend meter, **global** kill switch only), or their **own key straight from the browser** (no server policy, budget, kill or redaction) | `supabase/functions/claude/index.ts`; `app/src/lib/claude.ts:888-970` |
| A student wanting to pay | **Cannot.** `individualPaidAcquisitionApproved = false`. One $7.99 acceptance purchase was run on 2026-10-03 | `supabase/functions/billing-checkout/index.ts:27` (V); `docs/evidence/BILLING-LIVE-ACCEPTANCE-2026-10-03.md` |
| An institution | **Cannot activate.** No tenant, no connector, no contract, no entity. A sandbox adapter and synthetic demo exist | `app/server/institution/sandbox.ts`; `contracts/README.md` |
| An institution admin/registrar | Console, registration, gradebook, SCIM, LTI, config studio, offboarding all exist as server code with tests; none runs against a live tenant | register §3, §6 |
