# Program risk register (Phase 0)

**Purpose.** One ranked list of what stands between the repository and the Phase 1 gate, with an owner role, a Phase 1 action and a review date. **Date** 2026-10-04. **Base** `origin/main` `4adb8cc`. **Status** Phase 0 baseline — evidence-cited, not a readiness claim. Nothing was run against production; no `*.check.sql` or suite was executed for this register. Severity: P0 = could expose cross-tenant or person data, cause irrecoverable loss, or block the Phase 1 gate; P1 = must be fixed before any pilot touches real data; P2/P3 lower.

**How this relates to what exists.** [`LAUNCH-RISK-REGISTER.md`](../../LAUNCH-RISK-REGISTER.md) (launch), [`docs/program/03-RAID.md`](03-RAID.md) (programme RAID) and [`docs/security/`](../security/) already hold risks. This register does not replace them; it is the Phase 0 reconciliation against audit evidence. Owners are **roles**; per [`OWNER-AND-ACCOUNTABILITY-MATRIX.md`](../../OWNER-AND-ACCOUNTABILITY-MATRIX.md) one person holds every seat and the backup is unassigned (R-018), so "owner" here is accountability, not independence. Exceptions carry a review date; none is accepted yet.

Sources of each row: `DB` [tenant-boundary-map](../architecture/tenancy/tenant-boundary-map.md) / [privileged-surface-map](../architecture/security/privileged-surface-map.md); `AI` [ai-policy-enforcement-map](../architecture/ai/ai-policy-enforcement-map.md); `PLAT` [FITNESS_FUNCTIONS](../governance/FITNESS_FUNCTIONS.md); `PROD` [CAPABILITY_TRACEABILITY_MATRIX](CAPABILITY_TRACEABILITY_MATRIX.md) / [DOMAIN_OWNERSHIP_MATRIX](DOMAIN_OWNERSHIP_MATRIX.md); `COM` [READINESS_GAP_MATRIX](../../commercial/READINESS_GAP_MATRIX.md) / [PUBLIC_CLAIMS_APPROVAL_REGISTER](../legal/PUBLIC_CLAIMS_APPROVAL_REGISTER.md).
