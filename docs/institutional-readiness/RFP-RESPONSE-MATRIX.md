## Answer states

| State | Meaning | Response rule |
| --- | --- | --- |
| `VERIFIED — REPOSITORY` | exact implementation/test/document evidence exists | state revision/date/scope and missing target/operated proof |
| `VERIFIED — EXTERNAL` | current independent, contractual, operational or customer evidence exists | identify issuer, scope, environment, date, expiry and access restrictions |
| `CONDITIONAL` | capability requires named configuration, provider, approval or acceptance | list every gate; do not imply present availability/activation |
| `PLANNED / NOT AVAILABLE` | not sellable or operational today | answer directly; no delivery date without approved roadmap authority |
| `NOT SUPPORTED` | deliberately excluded | state boundary; do not imply an unapproved workaround |
| `OWNER TO SUPPLY` | repository cannot establish the fact | require accountable source evidence before submission |

## Submission control

Capture the issuing institution and workbook/version, deadline, instructions, amendments, authoritative question IDs, answer owner, dependencies, clarification log, exception/deviation list and required signatures. Review answers as a complete set for contradictions. Confirm every link/attachment is current, permitted for the recipient and scrubbed of secrets, personal data and unrelated tenant information. Freeze the submitted copy and record who transmitted it, when and through which approved channel.

Never copy an older library wholesale. If sources conflict, use the narrower current evidence state and queue the source for correction. A `Yes` must answer the exact question, not a nearby control.

## Evidence state

**Repository evidence.** Technical answer libraries, trust registers and procurement controls provide reusable, dated source material.

**Operational evidence.** No issuing customer, current questionnaire/workbook, approved answer set, authorized company facts, submitted response, contract award or customer acceptance is evidenced.

**Missing test/proof.** Load the exact RFP; map every question; revalidate all evidence and external facts; complete cross-functional/legal review; resolve contradictions/exceptions; authorize/freeze/transmit the response; retain receipt.

## Claim ceiling

Semester may say it maintains an evidence-gated RFP response process and draft source library. Each response requires current customer-specific review.

## Prohibited claims

Do not claim certification/compliance/conformance, penetration testing, live integrations, customers/references, uptime/SLA, recovery objectives, staffing, insurance, financial standing, pricing, signed terms, outcomes, production readiness, contract award or institutional approval without current authoritative evidence.
